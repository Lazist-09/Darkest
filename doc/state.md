## 已确认决策（只记结论 + 一句理由）

| # | 议题 | 结论 | 理由 |
|---|---|---|---|
| 1 | 平台 | PC / Steam | 用户选择 |
| 2 | 战斗框架 | 位置绑定技能的回合制战斗 | 用户明确要求 |
| 3 | 编队 | 2 支援位 + 4 战斗位；每格至多一个角色 / 空 / 障碍 | 用户明确要求 |
| 4 | 伤害类型 | 物理 / 精神双轴；距离轴近战 / 远程 | 用户明确要求 |
| 5 | HP 归零 | 不死亡 → 士气置底 + 判定 + 虚弱 | 用户明确要求 |
| 6 | 士气满 | 给自身与队友上增益（区别于美德） | 用户明确要求 |
| 7 | 暴击 | 伤害提升 + 为友方提升士气 | 用户明确要求 |
| 8 | 位置可变性 | 可变，位移 / 推拉 / 换位是核心博弈维度 | 位置固定会让"打敌方 X 号位"退化成"选目标" |
| 9 | 支援位定位 | 场上支援 + 与虚弱者对调位置，6 人始终在场 | 保持编队完整性 |
| 10 | 项目体量 | 先做垂直切片 | 先验证核心手感是否成立 |
| 11 | **核心爽点** | **绝境翻盘 + 精密操作，双轨并行** | 用户明确：两者都要 |
| 12 | **敌方编队** | **只有 4 个战斗位，无支援位** | 用户明确 |
| 13 | **行动顺序** | **速度属性排序**（新增速度属性） | 抢先手成为博弈，与眩晕/减速耦合 |
| 14 | **死门机制** | 死门抗性为固定上限；虚弱状态下受伤即判定，**判定成功 = 死亡** | 用户明确：换人名额有限，死亡一定会发生 |
| 15 | **失败条件** | 战斗位全空 → **先紧急补位，补不上才判负** | 避免"还有活人却判负"的别扭感 |
| 16 | **死门抗性方向** | **存活概率**（值越高越难死），原字面"判定成功=死亡"废弃 | 与"抗性"直觉一致，玩家不会误解 |
| 17 | **敌方深度补偿** | **三项全要**：敌方内部前后排 + 大型敌人占多格 + 增援/召唤 | 补上"切后排"消失后的深度缺口 |
| 18 | **士气数值框架** | **0~100，初始 50**；满 100 增益、触底 0 判定 | 空间对称，好调好理解 |
| 19 | **镜头布局** | 两侧 1 号位在中央隔"空气"对峙，编号由中向两侧递增；支援位 5/6 在外侧、平时不进镜头 | 用户明确 |
| 20 | **位移粒度** | **可推多格**，走**逐级交换链**（4→1 = 4↔3↔2↔1） | 用户明确 |
| 21 | **不可位移到空位** | 位移只能通过交换完成，不能走进空格 | 用户明确 |
| 22 | **障碍处理** | 障碍当作角色：**与障碍交换位置** | 用户明确 |
| 23 | **技能与空位** | 作用范围内**全空则灰显**；部分非空则只打非空位置 | 用户明确，避免打空挫败 |
| 24 | **向中靠齐** | 死亡/离场**立即**触发；**虚弱者不参与前移**；敌方对称 | 保护"换人"决策的意义 |
| 25 | **支援位可达性** | 只有部分敌人（远程/精神/AOE）能触及，命中时镜头移过去 | 避免"一虚弱就换人"变成无脑最优解 |
| 26 | **虚弱行动力** | 能行动但**显著减益** | 保留"赌一把继续用他 vs 换下去"的决策 |
| 27 | **士气波动幅度** | **小幅**：常规战斗稳定在 40~60，崩盘只在极端情况 | 用户明确 |
| 28 | **折磨 / 美德概率** | 由**角色固定属性（意志）+ 装备**决定，**不设保底** | 用户立场：纯随机就是对玩家的惩罚，要的是玩家主动控制士气 |
| 29 | **死门抗性** | **按角色分档**（具体档位待定） | 用户明确 |
| 30 | **暴击** | 在技能修正基础上 **1.5 倍**；暴击成功**给全队**加士气 | 用户明确 |
| 31 | **可控士气手段** | **四条全做**：支援位鼓舞 + 角色自带士气技能 + 暴击/击杀奖励 + 战前营地恢复 | 玩家要"主动控制士气"，手段必须先存在 |
| 32 | **死门分档** | **按角色定位**：坦克 80% / 战士 70% / 输出 60% / 辅助 50%（可调） | 用户明确 |
| 33 | **装备系统** | **切片不做**，意志 / 美德概率先用角色固定值 | 先验证战斗手感 |
| 34 | **目标玩家** | **硬核受苦型**：暗黑地牢 / 受苦类玩家，接受永久损失与高压 | 与本作设计最自洽 |
| 35 | **失败条件（重写）** | **战斗位角色全部死亡且支援位无人可补 = 失败** | 用户明确：否则全员缩在支援位就无敌了 |
| 36 | **撤退机制** | 战斗中可发起撤退 → **撤退判定**；成功则退出战斗 + 全员减士气，失败则该回合角色减士气 | 用户明确：给硬核玩家一条止损通道 |
| 37 | **虚弱减益** | 造成伤害 **-50%**、速度 **-30%**、HP 锁 1 | 保留"凑合用 vs 换下去"的决策 |
| 38 | **速度随机** | 实际速度 = 基础 ×(1 + **0~10%** 随机)，每回合重掷（已由 #163 从 0~20% 收窄） | 用户明确；我建议收窄，已采纳 0~10% |
| 39 | **障碍来源** | **关卡预置 + 敌人技能生成**，玩家不能主动清除 | 地形既是威胁也是位移素材 |
| 40 | **支援位定位（收窄）** | **只能使用对友方的增益技能，不能攻击**；站支援位每回合回士气 | 用户明确。顺带把"6打4"变"4打4"，压力对等 |
| 41 | **换位 / 增援（统一）** | 战斗位角色发起，指定支援位角色 B + 目标位 X；**X 有人则交换，X 空则直接进入**，结算后触发前移 | 用户澄清：是战斗位"召唤"支援位上来，不是支援位自己冲 |
| 41a | **换位冷却** | **不设冷却**，代价 = 发起者消耗本次行动 | 跳反收益已被"回士气只对虚弱者"抽掉，再叠冷却是叠床架屋 |
| 41b | **"不能攻击"的性质** | **位置限制**，不是角色限制 | 支援位角色被增援进战斗位后立刻能输出，交换才有意义 |
| 42 | **虚弱士气回升** | **基础值 + 站在支援位的【健康】队友数加成 + 精神抗性加成**，有最高值上限 | 用户明确：虚弱者互相陪伴不算，避免"全员虚弱互相奶" |
| 43 | **撤退士气代价** | 成功全队 **-10** / 失败全队 **-5**（#126 对齐 #118，原「该回合角色」作废） | 起手值，后续可调 |
| 44 | **士气增减表** | 采用起手值：暴击+5 / 击杀+10 / 受击-3 / 被暴击-5 / 队友虚弱-8 / 队友死亡-15 / 鼓舞+15 | 用户确认先跑起来再调 |
| 45 | **苟活漏洞裁决** | **不算判负，直到全灭才输** | 全员虚弱 = 全员 HP1 + 输出减半，代价自付；支援位无输出使其无法无限拖 |
| 46 | **撤退判定** | **混合式**：速度对比定基础成功率 + 随机（建议 ±10% 内，UI 显示数字） | 用户明确；我保留"五层随机"的反对意见 |
| 47 | **折磨生效方式（关键）** | **概率触发的特殊状态，不是硬封禁**：自私=每次被治疗有概率拒绝；恐惧=每次用技能有概率拒绝；失控=每次攻击有概率换目标 | 用户明确。这解决了"掐断救火手段"的担心——崩溃是变贵了，不是没救了 |
| 48 | **失控兜底** | 支援位角色中失控 → 改为**「捆缚」：无法行动** | 用户明确：防止伤害队友（支援位本就没有攻击技能） |
| 49 | **士气满 100** | 自身获得**一个美德**（持续**整场战斗**）+ 给全队加士气 + 自身士气回归 50 | 用户明确。用持续时间区分"经营出来的"vs"赌出来的" |
| 50 | **buff 持续时间** | 崩溃判定给的折磨/美德 → **3 回合**；士气满给的美德 → 整场 | 用户明确 |
| 51 | **眩晕** | **跳过本次行动** | 直观、代价明确 |
| 52 | **折磨池 / 美德池** | 折磨 3 个（恐惧/自私/失控）；美德 4 个（勇猛/坚韧/振奋/专注） | 用户选定；我建议切片阶段美德先做 2 个 |

| 54 | **战斗位失控** | **保留随机攻击**（未采纳我"统一改捆缚"的建议） | 用户拍板。风险已记录：可能打队友、破坏集火计划 |

| 58 | **增援范围** | **任意战斗位** | 自由度最高，代价已由"消耗行动"承担 |

## 我提出的风险（待与用户讨论）

1. ~~位置静态化风险~~ → 已解决（决策 8）
2. **士气判定负反馈螺旋**：折磨是大概率，一次倒霉 → 全队连锁崩盘，玩家归因于运气而非决策。建议美德概率随本场折磨次数递增（保底），或让支援位"鼓舞"成为可控干预手段。
