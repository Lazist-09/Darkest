### 【来自策划】🔴 **Curio（可交互物体）规格已落 —— 取代"随机事件"**（`#313`）
> **用户原话**：「**我不要所谓的随机事件，而是类似奇观一样的那种【可交互物体】**
> ⇒ 我去 wiki 取回了 DD 的 `Curios` 页，并把规格落成 🆕 **`doc/modules/curio.md`**。

- 🔴🔴 **① 先说 DD 的 Curio 核心机制（只有一条最重要）**
  ```
  🔴 **"正确道具 ⇒ 100% 确定的好结果"**
     例：Heirloom Chest ＋ 骷髅钥匙 ⇒ 【必定】传家宝 ×4
         Heirloom Chest ＋ 解毒剂   ⇒ 【必定】传家宝 ×3
         Heirloom Chest ＋ 空手     ⇒ 75% 传家宝 ×2 ／ 25% 流血·瘟疫
  ⇒ 🔴 所以 Curio 的乐趣【不在随机】，而在【玩家要记住/猜出"哪个道具对哪个物件"】✅
  ⇒ 而同一个 Curio 对【不同道具有不同等级的好结果】⇒ 玩家要权衡"省道具 vs 拿更多" ✅
  ```
  🔴 **还有一条狠的**：**"用错道具"也是【确定的坏结果】**
  ```
  Decorative Urn ＋ 铲子 ⇒ 【必定】得【负怪癖：愧疚】（"什么人会亵渎死者？"）
  ⇒ 🔴【记错了是有代价的】✅
  ```

- 🔴 **② 而我们的现状是"随机事件"**（`#272` 的"事件节点 = 必然代价 + 可选收益"）
  ⇒ ✅ 🔴 **好消息：`#272` 不需要推翻，它正好就是 Curio 的【空手结果表】** ✅
  ```
  #272 的"必然代价" = 空手碰有概率出坏结果 ✅
  #272 的"可选收益" = 用对道具 ⇒ 确定的好结果 ✅
  ⇒ 差别只是：从【二选一】变成【三选一：空手 / 用道具 / 走开】，且【结果由道具决定】
  ```

- 🔴 **③ 而 `#258`「事件【不允许跳过】」必须【作废】**
  ```
  #258 的理由：跳过 ⇒ 没有代价 ⇒ 退化成免费资源点
  🔴 但在 Curio 框架下【不成立】——
     · Curio 【不阻挡通行】（DD 原文）⇒ 它就是可选的 ✅
     · 而"空手碰"已有概率代价 ⇒ 🔴【不需要用"强制"来造代价】✅
  ⇒ ✅ 裁定：**Curio 允许【不碰，直接走】**，`#258` 的"不许跳过"作废
  ```
