## 1. 判据（V1~V6 · 骨架）

| # | 判据 | 判定式（可测） |
|---|---|---|
| **V1 经济闭环** | **赚得到、花得掉、再出发** | 金钱来源**可追溯**到「光照档 + 战斗数 + 事件」（**不得只跟趟数挂钩**）；**存在明确的支出出口**（减压 / 招募）；🔴 **"赚了没处花"或"只能花不能赚"都判失败**（`#236` 被推翻的根因就是"金钱无处可花"） |
| **V2 减压是真出口** | 士气**跨趟单调下降**的问题被真正解决 | 🔴 **`#245`「士气没有出口」的出口**：回城后**至少一种方式能把士气拉回来**（Tavern/Abbey）；**验证**：连续 N 趟（N≥3）跑图，**士气不必然归零/崩溃**；🔴 **副作用必须体现**（下一趟开局士气 −N，Tavern 概率高 / Abbey 更稳） |
| 🔴 **V3 Tavern vs Abbey 有取舍** | **同价同效、风险不同** | `price`/`effect` **相同**；**只有副作用形态不同** ⇒ **选择依据是"风格/风险偏好"，不是"哪个更优"**；⚠️ 若其中一个**严格更优** ⇒ **判失败**（退化成"选更优"） |
| **V4 招募有意义** | **免费 + 补的人不比老的强**，且**轮换成为策略** | `price == 0`；新兵 `level == 1`；**名册上限 12**（出征 6 + 替补 6）⇒ **"轮换休息"必须真的可行**（不是摆设）；⚠️ 若"永远用同一队"⇒ 判失败 |
| **V5 英雄个体化可用** | 名字 + 等级 + 特质**都能被看见并影响战斗** | 等级只给**属性小幅度**（HP+2/攻击+1）；特质 **2~3 条、正负都有、幅度小**；🔴 **不得出现技能升级**（那属 M8.1） |
| **V6 端到端可玩（红线 18）** | **启动 → 跑图 → 回城 → 花钱 → 再出发** 一条命令可复核 | 冒烟 `EXIT=0` 且无 `ERROR`；**走【启动场景】**（不得场景直载） |
