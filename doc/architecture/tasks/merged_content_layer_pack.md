## 4. 数据形态草案（字段级，供实现对齐）

```jsonc
// data/room_contents.json —— 内容层：房间类型 → 可能的编成池 + 权重（真机形态：hall:/room: .chance N .types …）
{
  "config": { "version": 1 },
  "rooms": {
    "hall":  [ { "weight": 2, "encounter": "fishman_patrol_a", "curio_pool": null },
               { "weight": 1, "encounter": "mixed_ambush_b",   "curio_pool": "common" } ],
    "room":  [ { "weight": 2, "encounter": "elite_guard_a",   "curio_pool": "rare"   } ],
    "branch":[ { "weight": 1, "encounter": null,              "curio_pool": "common" } ]   // 支路：可为空战斗（B2/B3/B4 约束仍适用）
  }
}
```
🔴 **三条读法**：**① `weight` 是组内权重**（不是全局）；**② `encounter` 引用编成 id**（不存在即启动报错）；**③ `curio_pool` 引用 `curios.json` 的池 id**（**引用而非拷贝** ⇒ 统一读取层、不统一文件）。
