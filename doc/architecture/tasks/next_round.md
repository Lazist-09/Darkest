#### §4.1.1 🔴 判据口径七条（**判"判据自身会不会假通过/假红"** · UI 设计师实测 · 架构登记为判据）

| # | 口径 | 反例（实测） |
|---|---|---|
| **①** | **覆盖层判定只认【能画底的 `Panel`/`PanelContainer` 类】**（纯容器遮不住任何东西） | 把 `MarginContainer` 当模态 ⇒ **审计范围被悄悄缩小 ⇒ 假绿** |
| **②** | **可见性用 `IsVisibleInTree()`（有效可见性）** | 面板 `Hide()` 后内部 `Label.Visible` 仍是 `true` ⇒ 被算重叠（**假红**，实测 8 对） |
| **③** | **重叠行必须带【矩形坐标】**（`pos=`/`size=`） | 只报"谁压谁"分不清【放错位置】还是【容器被挤爆】 |
| **④** | **模态必须真的满屏**：父是 `Node2D` 时 `FullRect` 锚点算不出尺寸、"只设 `Size`"又会被引擎覆盖 ⇒ 先造【锚点相等 + 显式 `Size` = 视口】的满屏 `Control` 宿主（`ModalHost`） | 实测：模态只有 min size ⇒ 内容挤左上角并压住光照条（6 对重叠） |
| **⑤** | **每屏跑满 N 次且读数一变就报**（只报前 N 次 ⇒ 同场景内换面板/开模态**完全审不到** = 漏审假绿） | — |
| **⑥** | **报告必须自带【口径自证】**：审计范围 + 覆盖层是谁/什么类/样式来源 + **全场景计数** + **范围外控件数** | 缺口径自证 ⇒ "绿"无法被复核 |
| **⑦** | 🔴 **瞬态特效层（`MotionLayer`）可例外跳过**（`#324` 期架构已批），**但两条前置条件必须成立**：**① 真瞬态**（用完即 `QueueFree`）**② `MouseFilter = Ignore`**（否则吞输入，违反 `#321`⑤）；**且报告要打印"跳过 N 个瞬态元素"**（**例外必须可审计**） | 消散中的伤害数字/闪白/暗角按设计会短暂叠在卡片上 ⇒ 算进判据只会变噪声 |

#### §4.1.2 🔴 并补一条【静态门禁建议】（判据查不出的一类缺陷）

```
症状：`.tscn` 的 `type=` 与脚本基类不一致 ⇒ 引擎报
  `Script inherits from native type 'CanvasLayer', so it can't be assigned to an object of type: 'PanelContainer'`
  ⇒ 🔴 **脚本根本没挂上 ⇒ 面板内容与交互全死**（地图屏实测 3 个：光照条 / 选路 / 背包格子；可见 Label 4 → 9 才发现）
🔴 而【布局判据对它天然免疫】—— "绿"可能只是"空" ⚠️
⇒ 建议加门禁：**扫 `.tscn` 的 `type=` 与 `ExtResource` 脚本的基类是否一致**（可静态做、成本低）
```

#### §4.1.3 🔴 一条实现坑（进契约，免得下一个人重踩）

```
`[Export]` 属性若写了初值 ⇒ Godot 序列化会【省略"等于类默认值"的项】⇒ 生成的 `.tres` 是**空的**（没有可调项）
✅ 正解：**属性不写初值、出厂值只在 `Default()` 里给**（UI 设计师实测：`ui_palette.tres` 33 项）
```
