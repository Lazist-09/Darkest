## 1. 验收判据（E7 · 7 项）

| # | 判据 | 判定式（可测） |
|---|---|---|
| **V1 完成率** | **6 场皆胜 → 落 [40,70]** | `runsCompleted / runsTotal ∈ [0.40, 0.70]`（`N=6` 实测后由策划校准区间） |
| **V2 单场层不退化** | A1 四项仍达标 | 胜率 ≥85% · 死门 ≤0.4/场 · 阵亡 ≤0.1/场 · 回合 4~6（**逐场统计，含夜袭场**） |
| **V3 损耗累积真实发生** | HP 曲线**后段斜率不为零**；`N=6` 总损耗 **显著 > 28%** | 每场结束 HP% 序列：`HP%[k+1] < HP%[k]` 在**后段**仍成立；`HP%[0] − HP%[6] > 0.28`（对照切片 `N=3` 的 28%） |
| **V4 扎营使用分布** | 🔴 **`扎营次数分布 / 用在哪几场`**（#241 修正：原"不是每次都扎"**必然成立、没有信息量**） | 统计 `每趟扎营次数`（0/1/2）与 `扎营发生在第几场后`（第 1~6 场）；**判读**：是否用满 2 次、是否倾向留到后段（`CampsUsed` 直方图 + `campAfterBattleIndex` 直方图） |
| **V5 `Starve` 有意义** | 出现"饿着过"的选择 | `foodTierCounts[starve] > 0`（说明口粮真的紧） |
| **V6 士气长线化生效** | 士气**跨场累积下降** + 回城惩罚可观测 | 士气序列后段 `morale%[k+1] < morale%[k]`；且存在 `TownReturnEvent.penaltyApplied > 0` 的记录 |
| **V7 决定性** | 同 seed 同结果 | 同 `runSeed` 两遍：**事件流逐条一致**（含 `DrawCount` 序列）；选路/夜袭/事件/敌人抽取**全部写 `RngDraw`** |
| 🔴 **V8 扎营技能"角色专属"** | **该原型的角色不能用别原型的扎营技能**（#242/#243） | **反向用例**：把 `medic_bandage`（`owner_archetype=medic`）交给**战士/坦克/政委** → **不可选/不可执行**（`Availability` 拒绝；命令被拒且**不消耗 Respite**）；正向：`medic_bandage` 交给**军医** → 可选。**逐条覆盖 12 个技能**（每原型 3 条）；UI 侧同时验收**跨原型技能不出现/灰显**。⚠️ **缺此条 ⇒"角色专属"会退化成"共享"** |
| **V9 跨场效果清算（O-67 已定）** | **`next_battle` 不结转 · `ambush_immunity` 保留至消耗或本趟结束** | ① **磨刀/加固甲胄**：构造"扎营用磨刀 → 本趟中止/回城（无下一场）" → **效果作废**（不得出现在下一趟）；构造"扎营用磨刀 → 打下一场" → **该场结束即清除**（`BuffRemovedEvent(Reason:"expired")` 可查）；② **轮流守夜/站岗**：构造"扎营用守夜 → 本次夜袭**未触发**" → **标记仍在**；再构造下一次扎营后触发夜袭 → **被免疫**（`AmbushTriggeredEvent(immunityConsumed:true, ambushSuppressed:true)`）且**不插入夜袭战**；③ **扎营清的与到期清的可分**（`Reason:"recovery"` vs `"expired"`） |

> **复测规模**：与 M6 同档——**≥300 个远征**（每远征 `6 + 夜袭次数` 场）；`--seed/--runs/--override` 语义不变。

## 3. 红线（与 `m7_expedition.md` 一致）

| 红线 | 说明 |
|---|---|
| **不改单场数值** | A1 已达标；M7 **只做远征层** |
| **`BattleDirector` 保持"单场纯"** | 每场工厂新建 → 同 seed 可复现单场（§9.12/§9.13） |
| 🔴 **扎营技能＝角色专属** | **`owner_archetype` 决定"谁能用"**；跨原型使用必须被拒（**V8**）——**否则专属退化成共享**（#242/#243） |
| 🔴 **`DurationType` 三义不可合并** | `until_next_recovery`（扎营清）≠ `battles:N`（扎营**不**清）≠ `next_battle`（仅下一场）——**#241** |
| **`deaths_door_recovery` 跨场保留 ≠ 战斗内 buff 清除** | 两者**并列、非冲突**；**不得当成"buff 未清干净"** |
| **撤退 = 该场失败 + 中止 run** | #233 已定，勿改 |
| **所有随机写 `RngDraw`** | 选路 / 夜袭 / 事件结果 / 敌人抽取 |
| **新增字段尾部追加 + 默认值** | 不破坏既有测试 |
| **P16 / P20 一致性** | `m_value` 公式一致（加载级 fail-fast）；远征层数据 7 条（P20） |
| **事件节点不允许跳过** | 必须二选一——否则事件无代价、退化成"免费资源点" |
