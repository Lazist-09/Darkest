## 1. 验收判据（E7 · 7 项）

| # | 判据 | 判定式（可测） |
|---|---|---|
| **V1 完成率** | **6 场皆胜 → 落 [40,70]** | `runsCompleted / runsTotal ∈ [0.40, 0.70]`（`N=6` 实测后由策划校准区间） |
| **V2 单场层不退化** | A1 四项仍达标 | 胜率 ≥85% · 死门 ≤0.4/场 · 阵亡 ≤0.1/场 · 回合 4~6（**逐场统计，含夜袭场**） |
| **V3 损耗累积真实发生** | HP 曲线**后段斜率不为零**；`N=6` 总损耗 **显著 > 28%** | 每场结束 HP% 序列：`HP%[k+1] < HP%[k]` 在**后段**仍成立；`HP%[0] − HP%[6] > 0.28`（对照切片 `N=3` 的 28%） |
| **V4 扎营被使用** | 扎营次数 `> 0`，且**不是每次都扎** | `campsUsed > 0` ∧ `campsUsed < maxCamps`（**每场后都可扎**，故需出现"不扎"的选择） |
| **V5 `Starve` 有意义** | 出现"饿着过"的选择 | `foodTierCounts[starve] > 0`（说明口粮真的紧） |
| **V6 士气长线化生效** | 士气**跨场累积下降** + 回城惩罚可观测 | 士气序列后段 `morale%[k+1] < morale%[k]`；且存在 `TownReturnEvent.penaltyApplied > 0` 的记录 |
| **V7 决定性** | 同 seed 同结果 | 同 `runSeed` 两遍：**事件流逐条一致**（含 `DrawCount` 序列）；选路/夜袭/事件/敌人抽取**全部写 `RngDraw`** |

> **复测规模**：与 M6 同档——**≥300 个远征**（每远征 `6 + 夜袭次数` 场）；`--seed/--runs/--override` 语义不变。

## 2. 复测必报字段（在 M6 的 9 项之上追加 ⑩~⑯）

| # | 字段 | 用途 |
|---|---|---|
| ①~⑨ | **沿用 M6 的 9 项**（胜率/回合/输出/死门/士气直方图/技能使用率/口径健康度/SP/待命） | 单场层判定 |
| **⑩** | **完成率（6 场皆胜）＋ 逐场胜负序列** | V1；序列可判定"死在第几场" |
| **⑪** | **每场结束的 HP% / 士气%**（曲线） | V3/V6 |
| **⑫** | **扎营次数 / 食物档位分布（Starve 占比）/ Respite 花费分布** | V4/V5；验证"给谁"的分配行为 |
| **⑬** | **资源收支（柴火 / 口粮 的得与失）** | 验证事件节点真的在供资源 |
| **⑭** | **夜袭触发次数** | 应 ≈ `0.33 × 扎营次数` |
| **⑮** | **撤退次数 + 当时死亡人数** | 验证两档惩罚（无死亡 −12 / 有死亡 −15） |
| **⑯** | **回城后的士气分布** | 验证"撤退不恢复到 50" |

> 🔴 **纪律**：以上字段**全部从事件流统计**（`logging.md` §1）；远征层新增事件见 `data_schema` **§3.11**。**缺字段即判该次基线不成立**；`D`/`E` 仍按**实测**标注（用词纪律 #216）。

## 3. 红线（与 `m7_expedition.md` 一致）

| 红线 | 说明 |
|---|---|
| **不改单场数值** | A1 已达标；M7 **只做远征层** |
| **`BattleDirector` 保持"单场纯"** | 每场工厂新建 → 同 seed 可复现单场（§9.12/§9.13） |
| **`deaths_door_recovery` 跨场保留 ≠ 战斗内 buff 清除** | 两者**并列、非冲突**；**不得当成"buff 未清干净"** |
| **撤退 = 该场失败 + 中止 run** | #233 已定，勿改 |
| **所有随机写 `RngDraw`** | 选路 / 夜袭 / 事件结果 / 敌人抽取 |
| **新增字段尾部追加 + 默认值** | 不破坏既有测试 |
| **P16 / P20 一致性** | `m_value` 公式一致（加载级 fail-fast）；远征层数据 7 条（P20） |
| **事件节点不允许跳过** | 必须二选一——否则事件无代价、退化成"免费资源点" |
