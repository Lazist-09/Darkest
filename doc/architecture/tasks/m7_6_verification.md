|---|---|---|
| **V1 地图生成（片 ①）** | **主干 6~8 + 支路另加（总房间 ≤10）；全图连通；同 seed 复现** | 🔴 **口径 (A)（`#294` ①）**：**主干 6~8**、**支路挂在主干房上**（**分叉点度数 ≥ 3**、支路尽头 = **死路**）、**总房间 ≤10**；**不卡总房间数**（理由：**节奏感由主干保证**，(B) 缩短主干**反而削弱节奏**；`battle_goal=3` **与房间数无绑定** ⇒ 卡总数**不解决任何判据**）；**所有随机写 `RngDraw`**；**P25 ①②③⑦**。实测：主干 6~8 / 含支路总 6~10 / 有分叉点 **198/200（99%）** / `RngDraw` **2596 条** |
| **V2 按段移动（片 ②）** | **新区域 −30 ／ 重走已探索 −10；"回头更便宜"可测** | `move.new_area = −30`（**沿用已调平的 `light.node_step`**，原则①）· `move.revisit = −10` · 🔴 **`|revisit| < |new_area|`**；**同一 `LightChangedEvent` 通道**（`reason` 区分 `advance`/`revisit`）；**不相邻移动即拒绝且不耗光**；**P25 ④⑦**。实测：起点→终点 **5~7 段**；只走新区域总耗 **−210~−150**（**对照旧线性 6×(−30) = −180 ⇒ 同量级、分布会变**） |
| 🔴 **V3 支路必须有往返代价（`#294` ① 补）** | **支路不是"纯赚"** | 🔴 **"多探索"必须付【重走代价】**（−10/段）；**验收：支路的总收益（掉落机会）不应压倒性划算**（至少**可感的往返代价**）—— ⚠️ 否则**多房间 = 多掉落机会 + 无代价 ⇒ 支路不是决策** |

| 🔴🔴 **V5 「越暗侦察越差」是【设计意图】，不得改（`#294` ②）** | **加成随变暗【单调不增】** | **`越亮 ⇒ 看得清（信息多）＋收益少（掉落少）` / `越暗 ⇒ 看不清（信息少）＋收益多（掉落多）` ⇒ 那才是【真实取舍】**；🔴 **若"越暗又看得清"，那"亮"就【没有任何理由】了**；⚠️ **规格从未写"越暗侦察越好"**（只写"**单调不增**"）⇒ **用例里的断言不得替契约定方向**（`#294` 已把该断言定性为**假设**）。<br>🔴 **监控项**：**接手流程后看 V10 三档取舍方向** —— **若激进档因"看不清"而完成率掉太多**（**而不是因为战斗难**）⇒ **"信息惩罚过重"，再议** |
