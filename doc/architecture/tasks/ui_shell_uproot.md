## §4 🔴 裁定三：两处**接口/纪律修正**（我作为架构要改的）

```

   **动作型 > 禁止型**）⇒ ✅ **正解**：**panel 声明"我需要哪些 base hud 组件"（或由 shell 按 panel 类型查表）**，
   **默认由 shell 决定** ⇒ **新 panel 忘了声明 ⇒ 走默认，而不是"没有 HUD"** ✓
   📌 判据：**"新加一个 panel 时，需要有人【记得】做某件事吗？"** —— 需要 ⇒ **接口形状不对** ✓

🔴 **② 层级必须写清（否则又一处"两处真值"）**：
   ```
   UIRoot（外壳：Base/Screen/Overlay）
     └─ 当前 Screen = 某个 panel（主菜单 / 城池 / 唯一场景）
          └─ 唯一场景内部：DungeonView 模式状态机（Battle ⇄ Map ⇄ Curio/Camp）   ← blueprint §9.17

   ⇒ 🔴 **判据**：**"换 ScreenLayer 的 panel" 与 "场景内切模式" 是【两个层级】的切换** ——
     ⚠️ **不得混用同一个 API**（否则"谁在管当前显示"会出现两处真值，`#325` D6 家族）✓
   ⇒ ✅ 并要求：**`ShowPanel` 只切换 Screen 层；`DungeonView` 的模式切换【不经 `UIRoot`】** ✓
```
