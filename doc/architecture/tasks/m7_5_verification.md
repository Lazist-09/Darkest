## 0. 本卡的目的（**唯一理由**）

> `#256/#257` 证明：**A1 与 A2 在 M7 的机制集合下【数学上不可兼得】**。
> 按**纪律 16 的推论**：**判据不可达时，缺的往往不是"数值"，而是"一个让玩家选择难度的机制"** ⇒ **本层就是那个机制**。
> 🔴 **所以本层不是"加功能"，是把难度从数值手里交回玩家手里** —— 只有那样，**完成率才是有意义的指标**（它反映玩家的风险偏好，而不是我们的调参）。

## 4. 红线（与 `m7_5_dungeon_layer.md` D7 一致）

| 红线 | 说明 |
|---|---|
| **不动单场数值** | A1 刚全绿 —— 本卡**只加机制** |
| 🔴 **不改 A2 的判据本身** | 本卡是**救** A2，不是**改**它；**仍不可达则按纪律 16 记录，不得调参硬凑** |
| **收益端必须是【补给】** | 无金钱 ⇒ 若只给难度不给收益，光照计退化成"**纯难度滑块**"，失去设计意义 |
| **SP 恢复物品必须配 UI 提示** | 否则"不带它 → 支援位废"是**陷阱**，不是决策 |
| 🔴 **四类 duration 不得合并** | `until_next_recovery`（扎营清）· `battles:N`（扎营不清）· `next_battle`（仅下一场）· 🔴 **`while_carried`（SP 物品：**只要在背包就生效，扎营/回城都不清**）** |
| **光照效果不得含 HP 字段** | 本层只改敌方 ACC/DMG/暴击 + 我方士气/暴击/侦察；**加 HP 就是把 #255 已否决的杠杆搬回来**（P21 ③） |
| **不得引入"偷袭/闪避"** | 会改单场行动序 ⇒ 动 A1 |
| **所有随机写 `RngDraw`** | 侦察 / 掉落 / 任何掷骰 |
