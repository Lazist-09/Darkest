## 0. 本卡的目的（**唯一理由**）

> `#256/#257` 证明：**A1 与 A2 在 M7 的机制集合下【数学上不可兼得】**。
> 按**纪律 16 的推论**：**判据不可达时，缺的往往不是"数值"，而是"一个让玩家选择难度的机制"** ⇒ **本层就是那个机制**。
> 🔴 **所以本层不是"加功能"，是把难度从数值手里交回玩家手里** —— 只有那样，**完成率才是有意义的指标**（它反映玩家的风险偏好，而不是我们的调参）。

## 1. 前置：**判据可同时成立性预检**（D5.0，纪律 16）

| 判据 | 内容 |
|---|---|
| **A1（单场层）** | 胜率 ≥85% / 死门 ≤0.4 / 阵亡 ≤0.1 / **回合 4~6** ← 🔴 **本卡不得动** |
| **A2（跑图层）** | **6 场皆胜完成率 [40,70]** ← **本卡要救的那条** |
| **新增（本层）** | **光照计被使用**（Black 档出现过）+ **风险/收益被选择**（有 run 在 **Dim 以下结束**） |

**方向检查**：A2 要"完成率 ↓" ⇒ 需要"**玩家主动选择更难**"；光照计提供的正是"**选择更难换收益**" ⇒ ✅ **方向一致，且是机制而非数值**。
⚠️ **但若玩家永远选最亮 ⇒ 完成率不降** ⇒ 所以**必须验"风险/收益是否真的被选中"**（这是本卡的**元判据**，不是可选读数）。

## 2. 判据（D5.1 · V1~V8）

| # | 判据 | 判定式（可测） |
|---|---|---|

| 🔴 **V4 风险/收益被选择（元判据 · 三档，`#259`/v1.00）** | **"摸黑"必须按精确口径统计** | 🔴 **"摸黑 run" 定义（写死）＝【结束时光照 ≤ 50】（Shadowy 及以下）** —— **不得用"中途经过 Shadowy"**（起手 100、每节点 −15 ⇒ 什么都不做也会在第 4 节点进 Shadowy ⇒ 几乎每个 run 都满足 ⇒ **没有区分度**）；反例对照：**一次不提亮 → 结束 ~10（摸黑 ✅）· 提亮 2 次 → ~70（不算）· 扎营 2 次 → ~70（不算）**。三档阈值（依据 = 混合完成率模型 `(1−r)×90% + r×X%`，落带取中 55% ⇒ **真正落带需摸黑占比 ~50%**）：<br>· 🔴 **V4a（硬下限，可判红）：摸黑 run 占比 ≥ 15%** —— **15% 时混合完成率 ≈ 81%（仍超上沿）** ⇒ 它**不是达标线，是"机制没死"的最低证据**<br>· **V4b（目标档，只报告）：≥ 40%** —— **达不到 ⇒ 是"摸黑不够有利可图"（该调收益端），不是"难度不够"**<br>· 🔴 **V4c（判据分层）：见 V1** |
| **V5 侦察有效** | 成功率与光照档**相关性成立**；有 run **因侦察避开精英战** | 侦察成功率 ≈ 档位加成后的期望；`pathChangedByScout > 0` |
| **V6 背包真取舍** | 起手配置**不是唯一解** | 起手配置分布 **出现 ≥2 种**（多种配置都能走通） |
| **V7 SP 物品有意义** | 不带它时 SP 真的不恢复；**玩家会权衡是否带** | `spRegen==0` 的不带组存在；**且 UI 必须提示"支援位不会恢复 SP"** |
| **V8 待命不越界** | 待命占**支援位回合**比例 **≤ 阈值** | 越界 ⇒ **调 SP，而不是加罚**（防"SP 太紧 + Pass 罚"变成二次惩罚） |
| **V9 决定性** | 同 seed 同结果 | 侦察 / 掉落 / 光照消耗 **全写 `RngDraw`**（`DrawCount` 序列逐条一致） |

## 4. 红线（与 `m7_5_dungeon_layer.md` D7 一致）

| 红线 | 说明 |
|---|---|
| **不动单场数值** | A1 刚全绿 —— 本卡**只加机制** |
| 🔴 **不改 A2 的判据本身** | 本卡是**救** A2，不是**改**它；**仍不可达则按纪律 16 记录，不得调参硬凑** |
| **收益端必须是【补给】** | 无金钱 ⇒ 若只给难度不给收益，光照计退化成"**纯难度滑块**"，失去设计意义 |
| **SP 恢复物品必须配 UI 提示** | 否则"不带它 → 支援位废"是**陷阱**，不是决策 |
| 🔴 **四类 duration 不得合并** | `until_next_recovery`（扎营清）· `battles:N`（扎营不清）· `next_battle`（仅下一场）· 🔴 **`while_carried`（SP 物品：**只要在背包就生效，扎营/回城都不清**）** |
| **光照效果不得含 HP 字段** | 本层只改敌方 ACC/DMG/暴击 + 我方士气/暴击/侦察；**加 HP 就是把 #255 已否决的杠杆搬回来**（P21 ③） |
| **不得引入"偷袭/闪避"** | 会改单场行动序 ⇒ 动 A1 |
| **所有随机写 `RngDraw`** | 侦察 / 掉落 / 任何掷骰 |
