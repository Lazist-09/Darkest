# 角色设计（模块）

> 主文档：`GDD.md` §0（切片范围）。本文件装角色定位、属性与技能池。

## 1. 切片角色 ✅

**决策（#127 / #140 / #144 / #145 / #146）：先做 4 个原型——战士 + 坦克 + 军医 + 政委（删掉鼓舞者与泛化「输出」，全部用具体职业名）。**

| # | 角色 | 定位 | 默认站位 | 死门抗性 |
|---|---|---|---|---|
| 1 | **战士** | 均衡战士 | 战斗位 | 70% |
| 2 | **坦克** | 护卫 + 嘲讽 + 控制 | 战斗位（前排 1 号） | **75%** |
| 3 | **军医** | 军医（伤害 + 治疗） | 战斗位 | **60%** |
| 4 | **政委** | 士气管理 + 带头冲锋 | 战斗位 | **60%** |

> **6 人满编编成（#143 / #147 / #149）**：

| 位置 | 角色 |
|---|---|
| 战斗位 1（前排） | **坦克** |
| 战斗位 2 | **战士** |
| 战斗位 3 | **政委** |
| 战斗位 4 | **军医** |
| 支援位 5 | **战士** |
| 支援位 6 | **军医** |

> 4 个原型让切片不仅能跑通系统链路，还能验证**编队深度**（坦克挡刀、政委抬士气、军医边打边奶）。
> ⚠️ 无「纯辅助」职业（#139/#140）：人人能打，增益/减益只是点缀（#141）。

## 2. 位置 — 技能覆盖原则 ⚠️（关键）

**每个角色在每一个他可能站的位置上，都必须至少有 1 个可用技能。**

这条不是锦上添花，是**必须**：

- 玩家把角色推到某个位置后，若一个技能都放不出来 → 该角色等于被废掉，体验极差；
- 战斗位角色被换到支援位后，若只会攻击 → 他在支援位无事可做；
- 支援位角色被增援到战斗位后，若只会增益 → 他上去就是个靶子。

**实现方式（草案）**：每个角色的 9 个技能按"站位要求"分布，保证覆盖。

✅ **分布比例已确认（用户拍板）**：

| 角色 | 战斗位 | 支援位 |
|---|---|---|
| 战士 | **7** | **2** |
| 坦克 | **7** | **2** |
| 军医 | **7** | **2** |
| 政委 | **7** | **2** |

### 7.1 输出定位（军医/政委 = 战士的 ~90%）

```
战士实际输出   = 攻击 12 × 倍率 1.0 = 12
军医/政委输出  = 攻击 11 × 倍率 1.0 = 11  → 约为战士的 90%，能打但不是主力
坦克实际输出   = 攻击 8 × 倍率 1.0 = 8    → 最低，靠护卫/嘲讽价值
```

> 军医/政委攻击力（11）低于战士（12），符合「能打但不是主力」的定位；坦克（8）最低。
> 军医治疗、政委鼓舞都只靠 2 个技能，是「救急」，不是「专职」。

```
旧参考：我方每回合输出 ≈ 12 → 击杀 4×30 HP 敌人 ≈ 10 回合（落在 8~12 区间）
```
