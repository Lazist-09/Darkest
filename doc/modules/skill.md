# 技能系统（模块）

> 主文档：`GDD.md` §2.4、§0.3。本文件装技能系统的完整结构。

## 1. 技能栏 ✅

**决策：战前从技能池选带 N 个。**

| 项 | 值 |
|---|---|
| 技能池大小 | **9** |
| 战前携带 | **5** |
| 战斗中能否更换 | `[待确认]` |

> ⚠️ **工作量提醒**：9 个技能 × 每角色。
> 切片 4 个角色 = **36 个技能**；6 个角色 = **54 个技能**。这对垂直切片是**很大的一块**。
> 建议二选一减速：① 切片先做 **4 个角色**（36 个技能）；② 技能池临时降到 **6 选 4**，验证后再扩到 9。
> 另一个现实问题：**每个角色的技能必须覆盖他在不同位置时的可用性**（§GDD 1.2），
> 否则玩家把他推到某位置后会发现"一个技能都放不出来"，体验极差。

## 2. 技能模板字段 ✅

| # | 字段 | 说明 | 必需 |
|---|---|---|---|
| 1 | 技能名 | — | ✅ |
| 2 | **自身站位要求** | 施法者必须站在哪些位置才能用 | ✅ 核心 |
| 3 | **目标位置** | 作用在哪些位置（我方/敌方 × 编号）——**是"可选目标池"，不是"命中范围"**（#178） | ✅ 核心 |
| 4 | 伤害倍率 | 基于攻击力的倍率 | ✅ |
| 5 | 命中修正 | 对基础命中的加减 | ✅ |
| 6 | 暴击修正 | 对基础暴击率的加减 | ✅ |
| 7 | **附加效果 + 触发概率** | 眩晕 / 流血 / 属性减益 等，各自过对应抗性 | ✅ |
| 8 | **位移效果** | 推 / 拉 / 交换 + 格数（逐级交换链，见 formation.md） | ✅ |
| 9 | **使用限制** | 无 / 冷却 N 回合 / 每场 N 次 / 每 N 回合一次 | ✅ |
| 10 | 士气影响 | 对自身 / 目标 / 全队的士气增减 | ⬜ 建议加 |
| 11 | 功能标签 | 输出 / 控制 / 位移 / 支援 / 治疗 | ✅ |
| 12 | 距离轴 | 近战 / 远程 | ✅ |
| 13 | 伤害轴 | 物理 / 精神 / 无伤害 | ✅ |

> ✅ 字段 2、3 是本作的核心：位置既是**使用门槛**也是**作用范围**，这两者分开表达。
> 字段 9「使用限制」是用户额外要求的：**除了冷却，还要能表达"整场只能用一次"**。

> 🔴 **字段 3 的目标语义（#178，必读）**：
> - **单体技能**（无 `aoe` 标签）→ 目标位置是**可选池**，在范围内**非空位置中选一个**；
> - **AOE 技能**（带 `aoe` 标签）→ 命中范围内**全部**非空位置；
> - `any_ally`（急救 / 战场鼓舞）→ **选一单体**；`team` → 全体友方；`self` → 自身；`adjacent_ally_and_self` → 自身 + 相邻。
> - **双段技能**（0.55×2 / 0.5×2）→ **同一目标打两段**，目标只选一次（#179）。
>
> ⚠️ 若实现为"范围内全命中"，劈砍会变成 0.9×2、敌方精准射击会变成 0.9×4，数值全盘失真（见 O-38）。

## 3. 三轴标签 ✅

**决策：在原有的距离轴 × 伤害轴之上，再加一层「功能轴」。**

| 轴 | 取值 |
|---|---|
| 距离轴 | 近战 / 远程 |
| 伤害轴 | 物理 / 精神 / 无伤害 |
| **功能轴**（新增） | **输出 / 控制 / 位移 / 支援 / 治疗** |

用途：
- AI 选技能时可按功能分类（如"缺治疗时优先治疗"）；
- UI 可按功能筛选 / 着色；
- 战前配装可以加约束，如"至少带 1 个位移""不能全带输出"。
  `[待确认：是否要加这类硬性约束]`

> 三轴**正交**：一个技能可以是「远程 + 精神 + 控制」，也可以是「近战 + 物理 + 位移」。

## 4. 使用限制 ✅

**决策：少数强力技能有冷却；同时保留"每场限用次数"作为另一种限制形式。**

| 类型 | 表达 | 适用 |
|---|---|---|
| 无限制 | — | 大部分常规技能，保证每回合都有事可做 |
| 冷却 N 回合 | `CD = N` | 强力输出 / 大范围控制 |
| 每场 N 次 | `每场 = N` | 救场技、终极技（如"整场只能用一次"） |
| 每 N 回合一次 | 变体 | 与冷却类似，但按固定节拍而非释放后计时 |

> 设计意图：让"强力技能"稀缺，但不至于让任何一回合无事可做。
> ⚠️ 注意：**支援位的「鼓舞」如果也吃冷却/限次，会直接削弱 §morale 的硬约束**
> （"可控士气手段必须够强够可靠"）。建议鼓舞类技能**不设限制**或限制很宽松。

## 5. 技能的可用性判定顺序

```
1. 该技能是否在战前携带的 5 个之内
2. 施法者当前位置是否符合【自身站位要求】
3. 目标位置是否合法（范围内是否"部分非空"，全空则灰显 —— GDD §1.2）
4. 使用限制是否满足（CD / 每场次数是否还有）
```
