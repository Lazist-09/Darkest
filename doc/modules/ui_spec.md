# UI 信息清单与规格（模块）

> **为什么这份文档存在**：本作的 UI 不是皮，是**核心机制的一部分**。
> 位置驱动 + 10 层随机的设计下，玩家**能不能看见**直接决定他能不能做决策——
> 看不见行动序列 = 无法规划；看不见撤退成功率 = 又一次掷骰；技能灰显不准 = 位置系统白做。
>
> 主文档：`GDD.md` §1.1 / §2.5 / §3.6；关联 `formation.md` §6、`combat_math.md`。
> 决策：#160。所有规格为**切片最小集**，不做视觉美术，只定**信息**与**交互**。

## 1. 屏幕分区

```
┌────────────────────────────────────────────────────────────────────┐
│ A 顶栏：  回合 3  │  行动序列 ▸ 政委 ▸ 敌2 ▸ 战士 ▸ 敌1 …  │ [撤退 68%] │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│ B 战场：  [辅6][辅5][战4][战3][战2][战1] ←空气→ [敌1][敌2][敌3][敌4]   │
│                                                                    │
│          支援位 5/6 平时不进镜头；被使用 / 被攻击时镜头短暂移过去       │
├────────────────────────────────────────────────────────────────────┤
│ C 角色卡：头像 │ HP 28/40 │ 士气 ██████░░░░ 62 │ [美德][流血]         │
│                            （当前行动单位，高亮）                     │
├────────────────────────────────────────────────────────────────────┤
│ D 技能栏： [劈砍] [横扫] [突刺✓] [短矛✗] [战吼]                      │
│            悬停 → 显示 命中率 / 伤害预估 / 目标范围 / 位移预览         │
└────────────────────────────────────────────────────────────────────┘
```

| 区 | 名称 | 常驻 | 说明 |
|---|---|---|---|
| A | 顶栏 | ✅ | 回合数、**行动序列条**、撤退按钮 |
| B | 战场 | ✅ | 6 我方位 + 4 敌方位，**位置编号必须可见** |
| C | 角色卡 | 切换 | 显示**当前行动单位**；也用于悬停查看任意单位 |
| D | 技能栏 | ✅ | 当前角色的 5 个携带技能 |

## 2. 必显示信息清单（🔴 硬性要求，缺一项体验即崩）

| # | 信息 | 为什么必须 | 出处 |
|---|---|---|---|
| 1 | **行动序列**（本回合 + 下回合预览） | 速度带 0~10% 随机浮动，**看不见就无法规划** | GDD §2.5 |
| 2 | **撤退成功率的具体数字** | 看不到数字，撤退就只是掷骰；看到"68%"玩家才会想"先杀掉最快的敌人再撤" | GDD §3.6 |
| 3 | **技能灰显 + 原因** | 位置系统的全部张力都在这；灰了要说明"站位不符"还是"范围内无人" | formation §6 / GDD §1.2 |
| 4 | **命中率** | 玩家要能围绕概率做取舍 | combat_math §1 |
| 5 | **目标范围高亮** | 悬停技能时，高亮所有会被命中的位置 | GDD §1.2 |
| 6 | **位移预览**（谁会被推到哪） | 位移是核心机制，**必须能在按下前看到结果** | GDD §1.3 |
| 7 | **士气条**（0~100 + 数值） | 士气是核心资源，玩家要能读出"还差多少到 100 / 还有多少到 0" | morale |
| 8 | **HP / 护盾次数 / buff 图标** | 护盾按次数（#156），要能看出还剩几次 | 本文档 §5 |
| 9 | **位置编号** | 所有技能都绑位置编号，编号不可见 = 技能描述读不懂 | GDD §1.1 |

> ⚠️ **第 6 条最容易漏**：位移走"逐级交换链"，中间单位会各退一格。
> 若只显示"目标被推 1 格"，玩家无法预判连锁结果——**必须把整条交换链的结果都画出来**。

## 3. 信息层级（同时显示时谁压过谁）

```
1 级（永远可见）：  位置编号 · 单位存活状态 · HP · 士气
2 级（常驻小图标）：buff / debuff · 护盾剩余次数 · 虚弱标记
3 级（悬停/选中）：精确数值 · 命中率 · 伤害预估 · 目标范围 · 位移预览
4 级（结算时）：   飘字（伤害 / 士气 / 死门判定结果）
```

- **2 级图标数量上限 4 个**，超出折叠为「+N」，点开看全部（对应 `buff.md` §8.1）。
- 优先级：死门 / 虚弱 > 折磨 > 美德 > 眩晕 / 捆缚 > 流血 > 属性增减益 > 护盾。

## 4. 操作流

```
① 轮到我方单位 → 该单位高亮 + 镜头轻微推近
② 玩家点技能
      · 可用   → 进入 ③
      · 灰显   → 不可点（**按钮只显示技能名，不内联显示"使用要求/不可用原因"**，#182）
③ 显示目标范围高亮 + 位移预览 + 命中率
③b 【仅单体技能】范围内可点选具体目标（#178）：
      · 🔴 **候选目标必须高亮**（范围内非空位逐个高亮，供玩家点选）——这是必需项，不可省
      · 范围内多个非空 → 玩家点选其一，选中项高亮 + 显示该目标的命中率/伤害预估/位移预览
      · 范围内仅一个非空 → 自动选中，可直接确认
      · AOE 技能（横扫/精神震荡）跳过本步：整个范围一起结算，不选单个目标
④ 玩家确认 → 结算
⑤ 结算反馈：伤害飘字 → 位移动画 → 士气飘字 → 状态变化（虚弱 / 死门 / 死亡）
⑥ 若触发死门判定 → **必须给一次明确的判定演出**（这是全作最紧张的一刻，不能悄悄结算）
```

- 🔴 **③b 是「精密操作」爽点的落点**（#178）：范围是**可选池**，单体技能必须让玩家能选中"打哪一个"。
  没有这一步，玩家就失去了"在敌 1、敌 2 之间选择"的战术决策，位置系统也退化成自动结算。
- 🔴 **"不显示使用要求" ≠ "不显示高亮"（#182 澄清）**：
  - **移除**的是②里技能按钮上的**使用要求文字**（"站位不符"这类规则说明书）；
  - **保留且必需**的是③b的**候选目标高亮**（选对象时哪些能打必须看得见）。
  - 🕓 **后续增强**：悬浮技能时高亮"该技能可用位置 + 攻击范围"——这是**技能自身站位/范围可视化**，与③b的选对象高亮是两件事，切片可先不做。
- **可撤销**：③/③b 阶段可取消重选（不消耗行动）。④ 之后不可撤销。
- **撤退**是常驻按钮，点开显示成功率 + 成功/失败的士气代价（-10 / -5），需二次确认。
- **增援**（§1.4.1 / #181）由战斗位角色发起，入口是技能栏旁的**一个**「增援」按钮：
  点按 → ① 高亮支援位 5/6 并选一个 → ② 高亮战斗位 1~4 并选一个 → 结算（两步间可取消）。

## 5. 状态显示规格

| 状态 | 显示方式 |
|---|---|
| **士气** | 横向条 + 数字。**接近 100 或 0 时变色预警**（≥85 金色 / ≤15 红色） |
| **虚弱** | 单位半透明 + 灰化 + 「虚弱」角标；HP 显示为 `1` 并加删除线示意"锁 1" |
| **护盾** | 单位外圈盾形图标 + **剩余次数数字**（#156，不是吸收量） |
| **守护** | 保护者与被守护者之间画一条连线（位置系统可视化，也让"推开就断开"看得见） |
| **嘲讽** | 敌人头顶「嘲讽」标记 + 指向坦克的箭头 |
| **折磨 / 美德** | 不同底色的角标；**美德要有明显正反馈**（光效/音效） |
| **失控** | ⚠️ **必须显著标注**（morale.md §5.1 缓解建议 2）：否则玩家不知道他会乱打队友 |
| **死门判定** | 结算时弹出**大字判定结果**（"死门 62% → 扛住了"），不能只飘个小数字 |

## 6. 结算反馈要求

| 事件 | 反馈 |
|---|---|
| 造成伤害 | 伤害飘字（**暴击用更大字号 + 不同颜色**）；暴击时全队士气 +5 要有可见提示 |
| **精神伤害** | **用区别于物理的颜色**（如紫/蓝）——因为只有它降士气（#157），玩家必须一眼分清 |
| 士气变动 | 单位头顶飘 `+5` / `-8`，**上浮绿色 / 下沉红色** |
| 位移 | 沿交换链**逐格滑动**动画，不能瞬移（要能看清谁被挤到哪） |
| 死亡 | 倒地演出 + 立即触发**向中靠齐**并播放补位动画（formation §6） |
| 士气满 100 | 明显的"士气高涨"演出（美德获取是重要正反馈） |
| 士气归 0 | 崩溃判定演出 + 折磨名称，**让玩家知道发生了什么** |

> ⚠️ **物理 vs 精神必须视觉可分**：#157 之后，玩家判断"这一下掉不掉士气"完全依赖这个区分。
> 若两者看起来一样，士气系统对玩家就是不可读的。

## 7. 边界与异常

| 情况 | 处理 |
|---|---|
| 支援位被攻击 | 镜头短暂移过去（§1.1），不能"屏幕外掉血" |
| 技能范围内全空 | 灰显 + tooltip「范围内没有目标」 |
| 范围内部分为空 | 正常可用，只高亮非空位置 |
| 位移撞边界 | 显示"撞墙"抖动反馈 + 「位移失败」提示 |
| 单位死亡导致序列变化 | 行动序列条实时更新，被移除的单位划掉 |
| 同回合多个单位死亡 | 靠齐逐个结算，每个都要有可见演出 |
| 战斗位全空 | 显示失败结算面板 |

## 8. 详情框规格（悬停）✅（#200 —— 本项由原"可延后"提升为**必做**）

**三类悬停对象共用一套详情框组件**，内容按类型切换。

### 8.1 触发与呈现

| 项 | 规格 |
|---|---|
| 触发 | 悬停 **150~250ms** 后出现（**防抖**：扫过不闪） |
| 位置 | 跟随鼠标 + **边界避让**（贴边自动翻转） |
| 层级 | **最高**（压过技能栏 / 角色卡 / 飘字） |
| 关闭 | 移开即关；可选"点击锁定"（便于对照两个单位） |
| 溢出 | 内部滚动，高度上限 ≈ 70% 屏高 |

### 8.2 技能详情（悬停技能按钮）

| 组 | 必显示 |
|---|---|
| 身份 | 名称 · **距离轴**（近战/远程）· **伤害轴**（物理/精神/无伤害） |
| 数值 | **伤害倍率** · **命中修正** · **暴击修正** · 段数（如 `0.55×2`） |
| 附加 | 每个附加效果的**类型 + 触发概率**（眩晕 / 流血 / 属性 ±值×回合） |
| 位移 | 推 / 拉 / 交换 / 自我移动 + 格数 |
| 限制 | 无 / CD N / 每场 N 次 |
| 士气 | 对自身 / 目标 / 全队的增减 |
| 标签 | 输出 / 控制 / 位移 / 支援 / 治疗 |
| **可用位置** | 自身站位要求——**只在悬停时显示**（#182 已定"按钮上不内联"） |
| **当前可用性** | 可用 / 灰显 + 原因（站位不符 / 范围内无人 / CD 中 / 每场次数用尽） |
| **对候选目标的预估** | 攻击技能 → 候选池内**每个目标**列出：**命中率 % + 伤害预估区间**（含减免后） |

### 8.3 单位详情

| 对象 | 内容 |
|---|---|
| **我方单位** | 名称 · HP（**精确数字**）· 士气（数值）· 速度 · 攻击 · 物防 · 韧性 · 四类抗性 · 当前 buff（图标列表，**可继续悬停**）· 虚弱 / 死门 · 折磨或美德 · 技能池 |
| **敌方单位** | 🔴 **全暴露（#200 用户拍板）**：名称 · HP（**精确数字**）· 速度 · 攻击 · 物防 · 韧性 · **四类抗性（精确百分比）** · 当前 buff · **完整技能表**（§8.4）· 移动模式（不能自由移动，仅由技能位移） |
| **意图区块** | 🕓 **切片不做**（#201）——**预留区块**，默认显示「**未知（需侦察）**」（§8.5） |

### 8.4 敌方技能表（全暴露）

- 紧凑列表呈现该原型的**全部技能**：技能名 · 轴 · 倍率 · 命中/暴击修正 · 附加效果+概率 · 位移 · CD · 目标位。
- ⚠️ **默认折叠**：点「查看技能表」再展开；展开后单项可再悬停看完整技能详情。
  > **理由**：`review.md` 风险 #7 警告——UI 不把关键信息画清楚，**「精密操作」会退化成「查表」**。
  > **数据全暴露**（用户要的）与**交互默认折叠**并不冲突：
  > 暴露是**可得性**，折叠是**不强迫玩家每次读 4 张技能表**。

### 8.5 敌方意图（预留接口，#201）

- 🔴 **切片不显示意图**（用户拍板）；**但架构上必须预留**，供后续「侦察」类技能启用：
  - `EnemyAi` 需提供**不掷骰的预览路径**（只读快照 + 同源决策）——
    否则"预览"会偷走随机数、**破坏确定性**（`blueprint` §8 铁律）；
  - 投射层预留 `IntentProjection(UnitId) → (SkillId, TargetSlots) | Unknown`；
  - 单位视图预留 `IntentRevealed` 标记（默认 `false`）。
- 呈现：`IntentRevealed == false` → 「**未知（需侦察）**」；`true` → 下一步技能 + 目标位。
- 📌 **后续**：真正启用时需一并定义"侦察"技能（耗时 / 范围 / 持续）——登记为后续议题，不在本包。

### 8.6 buff 详情（悬停 buff 图标）

| 项 | 内容 |
|---|---|
| 名称 + 极性 | 正面 / 负面（配色区分） |
| 来源 | 由谁施加（含技能名，若可得） |
| 剩余 | 剩余回合数 / 层数 / **次数**（护盾按次数 #156） |
| 具体效果 | **数值化**（如"受物理伤害完全无效，消耗 1 次"、"死门抗性 +20%"、"每回合全队士气 +3"） |
| 可否驱散 | 是 / 否 |
