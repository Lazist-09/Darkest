## 1. 命中判定

```
命中率 = 100 - 目标闪避 + 技能命中修正
命中率 钳制在 [55, 100]
命中   = rand(0,100) < 命中率
```

- 钳制下限 55%：防止高闪避 + 减命中修正堆出"必 miss"的挫败。
- 钳制上限 100%：**不做必中**，保留 1 层基础随机（这是"老虎机感"里最该保留的一层，因为它是玩家最直观能感知的概率）。

## 2. 伤害计算

### 2.1 物理伤害

```
基础值 = 攻击者攻击力 × 技能倍率
减免率 = 目标物防 / (目标物防 + 30)
实际伤害 = round( 基础值 × (1 - 减免率) × 暴击倍率 × 伤害浮动 )
```

- **减免用递减公式而不用减法**：减法在"高防低攻"时会出现 0 伤害或负数的死亡区域，递减公式永远收敛且高防边际递减。
- `伤害浮动`：默认 **1.0（关闭）**。需要手感时再开 0.9~1.1。**默认关闭是本作"反老虎机"立场的一部分**（见 §9 随机层数清点）。
- `暴击倍率`：1.5（未暴击 = 1.0）。

### 2.2 精神伤害（#158 · 韧性连续挂钩，推翻 #116 的分档）

```
精神减免 = 韧性 / 250，上限 40%
基础值   = 攻击者攻击力 × 技能倍率
实际伤害 = round( 基础值 × (1 - 精神减免) × 暴击倍率 × 伤害浮动 )
```

| 韧性 | 30 | 50 | 55 | 60 | 65 | 70 | 100 |
|---|---|---|---|---|---|---|---|
| **精神减免** | 12% | **20%** | 22% | 24% | 26% | 28% | 40% |
| （参考）美德率 | 25% | 35% | 37.5% | 40% | 42.5% | 45% | 60% |

> ✅ **为什么改（用户拍板："韧性理论上需要和精神减伤挂钩"）**：
> 原分档（<40 / 40~70 / >70 → 10 / 20 / 30%）下，我方 4 人韧性 50 / 55 / 60 / 65 **全部落在 20% 这一档**，
> 韧性在我方角色之间**只影响美德率、完全不影响减伤**——等于这条属性对玩家不可见。
>
> 改连续公式后：无跳变、**保留了原锚点**（韧性 50 仍是 20%，与原 40~70 档一致），
> 且**降韧性 debuff 现在同时削减伤 + 削美德率**，让施法者的「恐惧低语」成为真正的双威胁。

### 2.3 伤害取整与下限

- `round()` 四舍五入；**任何来源的伤害最低 1 点**（不出现 0 伤害的无效反馈）。

## 3. 位移判定

```
过抗性 = rand(0,100) >= 目标位移抗性
成功 → 走逐级交换链（formation.md §2）；失败 → 位移不生效，伤害/其它效果照常结算
```

- 位移**永远不产生空位**，撞障碍即交换，撞边界即失败（不动）。
- 位移**不产生伤害** → 不触发死门（#117）。

## 4. 附加效果判定（眩晕 / 流血 / 属性减益）

```
实际触发率 = 技能标注概率 × (1 - 目标对应抗性)
触发 = rand(0,100) < 实际触发率
```

> 用**乘法**而非减法：减法（40% - 30% = 10%）会让高抗性角色几乎免疫，控制技能直接废掉。

| 效果 | 数值（起手值） | 持续 |
|---|---|---|
| **眩晕** | 跳过本次行动，状态随即结束（§2.5） | 1 次 |
| **流血** | 每回合 **3** 点固定伤害，回合结束时结算 | **2** 回合 |
| **属性减益**（降攻/降防/降韧性/减速） | **固定值 -3**（速度也走固定值，§2.5） | **2** 回合 |

- 属性减益走**固定值不用百分比**：基础速度本身带 0~10% 随机浮动，百分比叠乘法会让实际值不可预估（§2.5 已有此结论）。
- 降韧性的减益会**连带降低美德概率**（美德率 = 10% + 韧性÷2）→ 施法者的「恐惧低语」是切片里最恶毒的一招，符合设计意图。

## 5. 士气变动结算（#157 · 只有精神类伤害降士气）

### 5.1 核心规则：物理不掉士气，精神才掉

```
受到【物理】类伤害   → 士气【不变】
受到【精神】类伤害   → 士气 -8（被精神暴击 -12）
AOE 精神伤害         → 每个目标 -5（AOE 折扣，避免一次技能打崩全队）
AOE 精神 + 暴击      → 仍 -5/目标（#166：折扣优先，暴击不放大士气）
```

> ✅ **为什么改（用户拍板）**：士气是**精神状态**——被刀砍不该动摇意志，被恐惧低语才该。
> 这比原设计自洽得多，而且带来三个连带好处：
>
> 1. **干掉一层随机**：原「50% 概率触发」这层不可规划随机直接消失（10 层 → 9 层，见 §9）。
> 2. **嘲讽不再反噬**：坦克挨物理打不掉士气 → 原「坦克必然第一个崩」的结构性冲突自动消失，**不再需要封顶**。
> 3. **施法者成为明确的战术目标**：唯一的士气压力源蹲在 4 号位（最深处），
>    "突破前排切掉施法者 = 解除士气压力" —— **敌方前后排深度这才真正成立**（§1.5.1 的设计意图）。
>
> ⚠️ **唯一例外：虚弱状态**。虚弱者受到**任何**伤害仍 -5 士气（每回合最多 1 次）。
> 理由：虚弱是濒死状态，"挨打 → 更晚归队"的压力链属于虚弱机制，不属于士气增减表。
> 但它确实与"物理不掉士气"有张力 —— **若你要完全统一，把这条也改成"仅精神伤害"，虚弱期会明显变短**。
>
> ✅ **组合行已拍板（#166/#167）**：
> - **AOE × 暴击** → 折扣 −5 优先（#166）：暴击只放大伤害，不放大士气折扣；
>   否则一次 AOE 暴击 ≈ 全队 −48，直接违背"避免一次技能打崩全队"的折扣本意。
> - **虚弱者受精神伤害** → −8/−12 与虚弱 −5 **叠加**（#167）：−5 独立生效且受每回合≤1 限制，
>   −8/−12 不受该上限约束。虚弱 −5 是"濒死挨打→更晚归队"的独立压力链，与伤害来源正交。

### 5.2 完整士气增减表（起手值）

| 事件 | 变动 | 对象 | 备注 |
|---|---|---|---|
| 受到**物理**伤害 | **0**（不再扣士气） | — | #157 |
| 受到**精神**伤害 | **-8**（被精神暴击 **-12**） | 本人 | #157 |
| 打出暴击 | +5 | 全队 | |
| 击杀敌人 | +10 | 全队 | |
| 队友进入虚弱 | -8 | 全队 | |
| 队友死亡 | -15 | 全队 | |
| 站在支援位（每回合） | +3 | 本人 | |
| 政委「战场鼓舞」 | +15 | 单一目标 | |
| 士气冲满 100 | **+10** | 全队（一次性） | |
| 撤退成功 | -10 | 全队 | |
| 撤退失败 | -5 | 全队 | |
| 虚弱状态下受伤（任意类型） | **-5** | 本人 | 每回合最多 1 次；§5.1 的例外，可改为「仅精神」 |

- ~~被暴击 -5~~：已删除（并入「精神暴击 -12」）。
- 士气钳制在 **[0, 100]**，不会越界。
- 事件触发顺序：**先结算伤害 → 再结算士气 → 再判定虚弱/死门**。

> ⚠️ **压力够不够？缓解已落地**
> 现在**施法者**（精神 AOE/低语）与**远程射手**（新增「威吓箭」精神低伤）两个来源能造成精神伤害。
> 若玩家开局秒掉施法者，射手仍能提供 -4 的次一级士气压力，士气系统不至于完全失效。
> 若 Monte Carlo 显示 `verification.md` §3 的「士气触底 ≥1 次」不达标，按此顺序调：
> ① 威吓箭 CD 2 → 1；② 恐惧低语每回合可用（已是）；③ 精神震荡也加 -5 士气；④ 单次提到 -12；
> ⑤ **最后**才考虑给近战小兵加一个低伤精神技能（会改动 3 原型配置）。

## 6. 虚弱 / 死门判定

```
HP 归零
  → 不死亡；士气立即置 0 并触发一次崩溃判定（morale.md §4）
  → 进入虚弱：伤害 -50%、速度 -30%、HP 锁定 1

虚弱状态下受到任何伤害
  → 先扣士气 -5（§5.2）
  → 立即死门判定：
        存活概率 = 死门抗性 - (处于折磨状态 ? 10% : 0)      （#123 折磨 -10%）
        存活 = rand(0,100) < 存活概率
```

- 伤害来源含：直接攻击、流血等持续伤害、护卫替挡的伤害（buff.md §7.1）。
- 位移撞墙 / 撞障碍**不产生伤害** → 不触发死门（#117）。

## 7. 节奏试算（用本文件公式反推）

### 7.1 单次伤害速查

| 攻击者 → 目标 | 算式 | 结果 |
|---|---|---|
| 战士 → 近战小兵 | 12 × 1.0 × (1 − 8/38) | **9** |
| 军医 → 近战小兵 | 11 × 1.0 × 0.789 | **9** |
| 政委 → 远程射手 | 11 × 0.95 × (1 − 4/34) | **9** |
| 坦克 → 近战小兵 | 8 × 0.9 × 0.789 | **6** |
| 近战小兵 → 战士 | 12 × 1.0 × 0.789 | **9** |
| 近战小兵 → 坦克 | 12 × 1.0 × (1 − 12/42) | **9** |
| 远程射手 → 军医 | 13 × 0.9 × 0.882 | **10** |
| 施法者 → 战士（精神） | 12 × 0.8 × (1 − 20%) | **8** |

### 7.2 回合数试算

```
我方战斗位 4 人理论输出/回合 ≈ 9 + 9 + 9 + 6 = 33
实际有效率（位置限制 + 目标死亡 + 命中 90% + 位移打断）≈ 55~60%
  → 有效输出 ≈ 18~20 / 回合
```

| 敌人 HP 方案 | 总 HP | 预计回合数 | 结论 |
|---|---|---|---|
| 原方案（40/40/28/26 = 134） | 134 | **~7 回合** | ❌ 快于 8~12 目标 |
| **建议方案（50/50/38/34 = 172）** | 172 | **~9 回合** | ✅ 落在 8~12 |

> ⚠️ **建议（待用户拍板）**：把敌人 HP 从 `40/40/28/26` 上调到 `50/50/38/34`。
> 这不违反 #124「单体 ≈ 战士」——#124 约束的是**攻防面板**，HP 是**节奏参数**。
> 敌人 4 个打我方 6 个、我方还有治疗与士气系统，敌人 HP 更高是合理的配平。
> 若 Monte Carlo 实测仍偏快，优先继续上调敌人 HP，而不是下调我方输出（#122 口径）。

## 8. 治疗与护盾

| 类型 | 公式 | 说明 |
|---|---|---|
| **治疗** | **固定值，不吃攻击力** | 急救 12 / 群体绷带 5。吃攻击力会导致"堆攻击=堆治疗"，破坏定位 |
| **护盾**（#156） | **抵挡 N 次物理攻击**，用完消失 | 铁壁 = **2 次，CD 4**。被抵挡的那次攻击**完全无效**。详见 §8.1 |
| **自我伤害** | 固定值（殊死一搏 6 / 舍身 8） | ❌ **不被护盾吸收**（自己扎自己，盾挡不住）；**可致死**（走死门判定） |

### 8.1 护盾：按次数，不是按点数（#156 · 用户拍板）

```
挂上护盾（次数 N）
  → 每次受到【物理类攻击】→ 消耗 1 次，该次攻击【完全无效】
  → 次数归 0 → 护盾消失
```

| 规则 | 结论 |
|---|---|
| 抵挡什么 | **仅物理类攻击** |
| 精神类攻击 | ❌ **穿透护盾** —— 伤害照常结算、士气照扣 |
| 持续伤害（流血） | ❌ 不消耗次数（流血不是"攻击"，每回合独立跳血） |
| AOE | ✅ 消耗 1 次（一次 AOE 算一次攻击） |
| 位移 | ❌ 不消耗次数（位移不产生伤害） |
| 自我伤害 | ❌ 不消耗次数（见上表） |
| 被抵挡的后果 | **完全无效**：不扣 HP、不触发死门、不触发虚弱、不进入后续结算步骤 |

> ✅ **为什么"只挡物理"**：盾牌挡得住刀，挡不住恐惧。
> 这与 #157「只有精神伤害降士气」**同向强化**——施法者成了唯一能同时绕过护盾、又打击士气的威胁，
> "优先切掉施法者"这个战术目标因此更明确。
>
> ⚠️ 连带建议：**守护（护卫）同理** —— 建议护卫也只重定向**物理攻击**，精神攻击无法替人代挨（见 `buff.md` §7.1）。
>
> 📌 数值：铁壁 **2 次 / CD 4**。10 回合最多放 2~3 次 ≈ 抵挡 4~6 次攻击。
> 若实测偏强，优先降次数到 1 或把 CD 提到 5，而不是加血量吸收。

## 9. 随机层数清点（"老虎机感"自查）

本作目前共有 **9 层随机**（#157 减掉一层），按"是否可规划"分三类：

| 层 | 是否可规划 | 备注 |
|---|---|---|
| 命中 | ✅ 可规划 | 显示命中率 |
| 暴击 | ✅ 可规划 | 显示暴击率 |
| 附加效果触发 | ✅ 可规划 | 显示概率 |
| 位移过抗性 | ✅ 可规划 | 显示位移抗性 |
| 死门判定 | ✅ 可规划 | 显示死门抗性 |
| 崩溃判定（折磨/美德） | ⚠️ 半可规划 | 美德率 = 10% + 韧性÷2，可见 |
| **速度浮动 0~10%** | ⚠️ 半可规划 | 已由 #163 收窄到 0~10%（原 0~20% 打乱行动顺序、最易归因运气）；UI 必须显示行动序列 |
| **撤退判定** | ⚠️ 半可规划 | **必须显示成功率数字**，否则等于掷骰 |
| **折磨触发 33%** | ❌ 不可规划 | 折磨生效时才知道 |

> ✅ **#157 顺带减掉一层**：原「受击 50% 概率扣士气」是全部随机层里**最难受的一层**——
> 玩家什么都做对了还是会掉士气，且完全无法预判。改为"只有精神伤害才扣"后直接消失，**10 层 → 9 层**。
>
> ⚠️ 剩下的不可规划层里，**速度浮动 0~10%** 已收窄（#163）——它打乱的是玩家精心排好的行动顺序，失败时最容易归因为运气（§2.5）。
