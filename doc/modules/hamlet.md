## 0. 定位：M8 要补上那个**「没有出口」**

```
#245 定了【回城士气完全不恢复】⇒ 士气跨趟累积 ⇒ 最终必崩
🔴 而当时策划就记了：「DD 的出口是 Tavern / Abbey（花钱减压）——【我们 M7 没有】」
⇒ 🔴 M8 就是那个出口。而"出口要花钱" ⇒ 需要【金钱】⇒ 需要【经济】
```

**一句话**：**M8 = 给"跑图"一个存在意义**（赚资源 → 花资源 → 更强的下一趟）。

## 1. DD 的 Hamlet（**wiki 原文，照抄用**）

| 建筑 | 作用 | 升级用传家宝 |
|---|---|---|
| **Tavern** | **减压**：喝 / 赌 / 妓院 | Portraits + Crests |
| **Abbey** | **减压**：冥想 / 祈祷 / 鞭笞 | Busts + Crests |
| **Blacksmith** | 升级**武器 / 护甲**（付费） | Deeds + Crests |
| **Guild** | 升级**战斗技能**（付费） | Portraits + Crests |
| **Sanitarium** | **除负面怪癖 / 锁正面怪癖 / 治病** | Busts + Crests |
| **Stage Coach** | 🔴 **免费招募英雄**（每周更新） | Deeds + Crests |
| **Nomad Wagon** | 卖**饰品**（每周不同、价高） | Crests |
| **Survivalist** | **教扎营技能**（付费） | Crests |
| **Ancestor's Memoirs** | 剧情 / 日志（击败 boss 解锁） | — |
| **Graveyard** | 🔴 **记录每次死亡**（谁杀的、何时） | — |
| **Districts**（DLC） | **被动加成**（需 Blueprints） | — |

**三种货币**：**金钱 Gold** + **传家宝（Busts / Crests / Deeds / Portraits）**

### 🔴 DD 的五条关键设计（值得照抄）

```
① 【每个建筑固定需要同样几种传家宝，但数量递增】
   ⇒ 那是"长期投入曲线"的载体 —— 玩家知道该攒什么，但永远不够 ✅
② 【Tavern 与 Abbey 同价同效，但风险/收益不同】
   ⇒ Tavern：副作用更常见（负面怪癖），但正面结果更多
   ⇒ Abbey：更安全（副作用少），但正面也少
   ⇒ 🔴 那是"玩家选风格"的载体，而不是"一个更优" ✅
③ 【Stage Coach 免费招募】+【永久死亡】⇒ 英雄是【消耗品】
   ⇒ 那支撑了整个长线循环 ✅
④ 【Graveyard 记录死亡】⇒ 几乎零成本，但情感回报极高 ✅
⑤ 【升级有两条轴】：降低费用 ／ 解锁更高阶
   ⇒ 不只是"变强"，还有"变便宜" ⇒ 让"升级"这件事本身有梯度 ✅
```

## 4. M8.0 规格（🔴 **本文件先只做这一层**）

### 4.1 金钱 ✅（照抄 DD 的"战斗/战利品给钱"）

| 来源 | 量 |
|---|---|
| 战斗胜利 | 按**光照档**给（**越暗越多** —— 与 `#276` 同源 ✅） |
| 事件节点 | 二选一里加"钱"的选项 |
| 跑图完成 | 按**完成的战斗数**（呼应 `#273` 的战斗目标） |

🔴 **为什么金钱必须与光照/战斗挂钩**：**它让"冒险"终于有了可积累的回报** ✅
（`#276~#278` 的"摸黑搏补给"是**单趟内**的；金钱是**跨趟**的 ⇒ 那才是长线动机）

### 4.2 招募 ✅（Stage Coach）

```
· 回城后可招募新英雄（**免费**，照抄 DD）
· 名册上限（起手 8）· 每次回城刷新可选
🔴 需要先做【英雄个体】—— 而我们现在是"4 原型固定 6 人"
⇒ 🔴 M8.0 必须先引入【英雄个体】（一个原型可以有多个实例，各自有名字/HP/士气）
```

> ⚠️ **这是 M8.0 真正的工作量所在**：**从"6 个固定单位" → "可增删的名册"**。
> ⚠️ **并连带推翻 `#236`**「不做招募」—— 因为**没有招募，金钱就无处可花** ✅

### 4.3 减压（Tavern / Abbey）✅

| 场所 | 效果 | 副作用 |
|---|---|---|
| **Tavern** | 恢复到基准（50）**±** 波动 | 🔴 **概率触发负面**（下一趟开局士气 −N） |
| **Abbey** | 同上，**幅度更稳** | ✅ **副作用概率更低**，但**正面也更少** |

```
· 花钱：按"要恢复多少士气"计价（照抄 DD 的分档服务）
· 🔴 治好 Affliction（折磨）也靠这里 —— 呼应 DD 的"任务结束仍是 Afflicted"
```

### 4.4 M8.0 的验收

| 项 | 判据 |
|---|---|
| **金钱闭环** | 跑图赚钱 → 回城花钱 → 下一趟**可观测地更强** |
| **减压是真的出口** | 连续 3 趟的士气曲线**不再单调下降**（`#245` 的"必崩"被解除） |
| **Tavern vs Abbey 有取舍** | 两者**都不是严格更优**（存在"选哪个"的场景） |
| **招募有意义** | 阵亡后能补人；且**补的人不比老的强**（否则老的没价值） |
| 🔴 **端到端可玩** | **从启动能走到：跑图 → 回城 → 花钱 → 再出发**（`#279` 的教训） |

## 5. 🔴 顺序：**入口并入 M8.0 的验收**（`#282` 用户拍板）

```
🔴 现状：地牢层做完了但【没有入口】（project.godot 的 main_scene 仍是 Battle.tscn）
```

**用户拍板**：**先做 M8.0**（不单独先接入口）。

✅ **但不冲突** —— 因为 **M8.0 的验收本来就要求端到端可玩**：

```
M8.0 验收 = "启动 → 跑图 → 回城 → 花钱 → 再出发" 可走通
⇒ 🔴 那必然需要【入口】⇒ 所以"接入口"不是被跳过，而是【成为 M8.0 的一部分】
⇒ 这也符合 #279 的教训：凡新增入口，验收必须含"从启动可达"（不是"场景直载"）
```

**执行顺序**：

```
① 英雄个体化（原型的多实例 + 名册）
② 金钱（来源：光照档 / 战斗数 / 事件）
③ 回城场景（Hamlet）+ 入口接线（main_scene 或 MainMenu）
④ 减压（Tavern / Abbey）
⑤ 招募（Stage Coach）
⑥ 端到端冒烟：启动 → 跑图 → 回城 → 花钱 → 再出发
```

## 7. ✅ 已定（v1.23，用户拍板，`#283`）

| # | 项 | 定案 |
|---|---|---|
| **7.1** | **金钱尺度** | ✅ **先定比例**：**一场战斗 = 1 单位**；**一趟（含完成奖励）≈ 3~6 单位**；**一次减压 = 3 单位**<br>⇒ **一趟的钱大约能减 1~2 次压**；**绝对值待实测校准** |
| **7.2** | **英雄个体化** | ✅ 🔴 **名字 + 等级 + 个体差异**（**一步到位** —— 连带见 §3 的重排）<br>⇒ **等级**需要成长路径 ⇒ **战斗给经验**；**个体差异** ⇒ **需一组特质** |
| **7.3** | **减压副作用** | ✅ **下一趟开局士气 −N**（**与"士气是长线资源"直接挂钩**）；**Tavern** 概率更高，**Abbey** 同价同效但更稳 |
| **7.4** | **名册上限** | ✅ **12**（出征 6 + 6 替补）⇒ **"轮换休息"成为策略**（没减压的人先休息） |
| **7.5** | **"周"的概念** | ✅ **目前不引入，后续引入**（等有商店/饰品时再加 —— 那时"每周固定刷新"才有意义） |

### 🔴 由 7.2 连带出的新增设计点（M8.0 内必须一起定）

| # | 新问题 | 定案 |
|---|---|---|
| **7.6** | **等级的上限与成长曲线** | ✅ **1~6 级；只给【属性小幅度】**（如 HP +2 / 攻击 +1）<br>🔴 **不升技能**（**技能升级留 M8.1** ⇒ 与 DD 的 Guild 对应） |
| **7.7** | **"个体差异"的粒度** | ✅ **每人 2~3 条【小幅特质】**（如 +5% 伤害 / −10% 士气伤害）；**正负都有**<br>⇒ **招募刷新与后续清除（M8.2）才有意义** |
| **7.8** | **特质与 `#258`「扎营技能按原型」如何共存** | ✅ 🔴 **特质【不碰技能表】** —— 只影响**属性与士气**（+5% 伤害 / −10% 士气伤害 之类）<br>⇒ **`#243`「只用角色专属扎营技能」保持不变** ✅<br>**理由**：**"原型的技能 + 特质偏移"会让"角色专属"退化成"每人一套"** ⇒ 而 `#243` 的裁定正是**"扎营能力完全由'带了谁'决定"** ✅ |
| **7.9** | 🔴 **等级会不会破坏 A1** | ✅ **A1 按【新兵等级】测**（刚招的 1 级队必须达标）；🔴 **高等级队【另立判据】**（应该更严 —— 他们该打更难的活）<br>**理由**：**长线成长 × 单场判据是天然矛盾**（纪律 16）⇒ **不是"让 A1 恒成立"，而是"分层立判据"** ✅ |

> 🔴 **7.9 的处置值得记**：**面对"成长 vs 判据"的矛盾，答案不是"让判据不变"，而是"给不同成长阶段立不同判据"** ——
> 这与 `#271`「把判据换成能反映设计意图的那一个」**是同一手法**（**升级判据，而不是压制设计**）✅
