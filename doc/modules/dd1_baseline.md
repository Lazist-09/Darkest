## §7 ✅ 条 4 前置裁定：**`O-95` 4v4 vs 6 槽**（`#419` · 用户裁 · 2026-09-18）

### 7.1 🔴 原版依据（**一手铁证**）

```
🔴 **E 盘 `heroes/abomination/abomination.info.darkest` 实测**：
   `combat_skill: .id "transform" … .launch 4321 .target  …`      ← 4 个 rank 全可
   `combat_skill: .id "manacles"  … .launch 32   .target 123 …`   ← 只能在 rank 3/2
   `combat_skill: .id "vomit"     … .launch 32   .target ~23 …`   ← `~` = 全体敌方
⇒ 🔴 **掩码字符只有 `1` / `2` / `3` / `4`** ⇒ **原版 rank 就是 4 个** ✅ —— **从没出现 `5` / `6`** ❗
🔴 **`support_slot` / `reserve` / `backup_slot` ⇒ 【零命中】** ✅
   ⇒ 🎖️ **确认：原版 DD【没有"支援位"概念】** —— **那是我们自加的** ✅
📌 顺带：`abomination` 有 `.valid_modes human beast` + `.human_effects` / `.beast_effects`（**变身**）——
   那是 DD 的 Abomination 机制，**我们没有**（属职业/内容，另记）
```

### 7.2 我们现状

```
`formation.json`：`player{ slot_count: 6, combat_slots: 4, support_slots: [5,6] }` · `enemy{ slot_count: 4, combat_slots: 4 }`
⇒ 🔴 **slot 5/6 = 我们自加的"支援位"** ⚠️（牵连 SP / `O-60` · 6v4 行动经济 / `O-43`）
```

### 7.3 ✅ 裁定：**(c) 折中 —— 战斗 4v4，「支援位」改成【非战斗】概念**

```
✅ **取 (c)** —— 两条同时成立：

   ② ✅ **「支援位」改成【非战斗】概念 = 后备 / 轮换**
      ⇒ **不在场上 · 不进战斗行动序 · 不占 rank** ✅
⇒ 🎖️ **而 (c) 的价值**：**"复现原版"与"保留我们的想法"两边都保住** ✅
