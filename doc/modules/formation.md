# 模块：编队与位移

> 状态：部分确认 · 版本 v0.1 · 更新 2026-09-08
> 主文档：../GDD.md §1

## 它解决什么问题

位置是本作**唯一的核心资源**：所有技能都绑定位置编号，站对位置 = 能用技能，被推走 = 技能失效。位移则是玩家与敌人争夺这一资源的手段，直接承载「精密操作」这条爽点。

## 与核心循环的耦合

- 秒级：每个回合玩家在判读"我现在站哪儿、能放什么、把谁推到哪儿"。
- 分钟级：一场战斗中阵型被反复打乱与重整，靠位移与换人维持。
- 耦合强度：**极高**。这是整个战斗系统的骨架，不是附加系统。

## 1. 镜头布局（已确认）

```
镜头中： [辅6] [辅5] [战4] [战3] [战2] [战1]  ←空气→  [敌1] [敌2] [敌3] [敌4]
```

- 我方 1 号位与敌方 1 号位在屏幕中央隔"空气"对峙。
- 编号**由中间向两侧递增**：1 最靠前（最靠近敌方），6 最靠后。
- 支援位 5、6 在更外侧，**平时不进镜头**，只在换位 / 被攻击时入镜。
- 敌方只有 4 个战斗位，编号同样由中间向外递增，只到 4。

## 2. 位移规则（已确认）

| 规则 | 内容 |
|---|---|
| 粒度 | 可推**多格**，由技能指定格数 |
| 实现 | **逐级交换链**：从 4 到 1 = `4↔3` → `3↔2` → `2↔1` |
| 空位 | **角色不可位移到空位置**，位移只能通过交换完成 |
| 障碍 | 障碍**当作角色处理**：撞上障碍 = 与障碍交换位置 |
| 方向 | 推 / 拉 / 交换 / 自我移动，均走同一套交换链 |

### 交换链示例

初始：`[A][B][C][D]`（位置 1~4）

D 向前移动到 1 号位：
```
初始  1:A  2:B  3:C  4:D
D↔3 → 1:A  2:B  3:D  4:C
D↔2 → 1:A  2:D  3:B  4:C
D↔1 → 1:D  2:A  3:B  4:C
结果  1:D  2:A  3:B  4:C      ← A/B/C 各后退一格，D 抵达目标
```

### 设计后果

- 位移**不产生空位**，阵型长度恒定 → 位移改变的是**顺序**而非**间距**。
- 好处：阵型永远可读，UI 不需要处理"空洞"。
- 代价：位移无法把队伍拉散，破坏力主要体现在**打断敌方技能可用性**上。
- 因此位移强度主要来自"让谁站到几号位"，而不是"制造空隙"。

## 3. 向中靠齐（已确认）

| 规则 | 内容 |
|---|---|
| 触发 | 角色**死亡或离场（且无人替换）时立即**触发 |
| 方向 | 后方角色向 1 号位方向靠齐，空位只留在队尾 |
| 虚弱者 | **不参与前移**，健康角色跨过他补位 |
| 障碍 | **不阻挡靠齐**：后方单位前移时与障碍交换位置（障碍被推后），空位照样被填（#114，与 §2「障碍当角色交换」一致） |
| 全虚弱兜底 | 后方全是虚弱者时**空位留空，不补**；虚弱者恢复后也**不自动前移**（靠齐只在死亡/离场瞬间触发一次，#115） |
| 敌方 | **对称执行** |

### 为什么虚弱者不参与前移

如果虚弱者也跟着靠齐，那么"把虚弱者换到支援位保护起来"这个决策会被系统自己撤销——前面一死，他又被顶回战斗位挨打。换人机制就失去意义了。

### 副作用（需要跟进）

靠齐会让人数减少时阵型依然紧凑，因此"战斗位全空"几乎等同于"全队覆灭"。
→ GDD §3.5 的失败条件需要按此重新校准。

## 4. 技能与空位（已确认）

- 技能有**作用范围**，可覆盖多个位置（如「敌方 1、2 号位」）。
- 作用范围内**全部为空** → 技能**灰显，不可释放**。
- 作用范围内**部分非空** → 只对非空位置生效，**不浪费、不落空**。

> 这条规则让玩家不会被"打空"坑掉一个回合，同时保住了"位移后技能失效"这一策略张力。

## 5. 边界条件（已收口，决策 #78 / #88 / #114 / #115 / #39 / #41 / #22）

| # | 议题 | 结论 |
|---|---|---|
| 1 | 最外侧被向外推 | **位移失败，单位不动**（边界即硬墙，#78） |
| 2 | 靠齐是否被障碍阻挡 | **不阻挡**：与障碍交换、障碍被推后（#114，与 §2「障碍当角色交换」一致） |
| 3 | 后方全是虚弱者谁补位 | **留空位，不补**；恢复后也不自动前移（#115） |
| 4 | 敌方位移能力 | 敌人**不能主动移动**，位移只来自技能（#88，与玩家对称） |
| 5 | 能否主动推动障碍 | 障碍参与交换链，可被位移**交换推动**；但玩家**不能主动清除**（#22 / #39 / #73） |
| 6 | 支援位主动换位到战斗位 | 由**战斗位发起**换位/增援指定支援位角色，支援位不自冲（#41） |
| 7 | 障碍来源与生成 | **关卡预置 + 敌人技能生成**；切片只用关卡预置（#39） |

## 6. 验收标准

- 任意一次位移后，阵型长度不变、无空位产生（除非有单位离场）。
- 死亡后阵型在**同一时刻**完成靠齐，玩家能看清是谁补上了谁的位。
- 玩家在释放技能前，能明确看出"我这个技能现在能打到谁"（灰显状态准确）。
- 敌方被位移后，其技能可用性在同一回合内发生可见变化。
