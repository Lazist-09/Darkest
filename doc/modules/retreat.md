## §2 🔴 关键裁定：**撤退后，那一格算【已处理】**

```
🔴 **DD 的依据**：**DD 的战斗是【遭遇战】**（走廊 / 房间里的一次性遭遇）——
   撤退后**那场战斗消失了**（那格变空 / 视为已过）✅
⇒ ✅ **我们的战斗也是"格上的遭遇"** ⇒ **撤了就算【避过】** ✅
⇒ 📌 **即：撤退后【不会】再走回去重打同一场**（**重复消耗同一格没有意义**）✅
```

### 🔴 而它必须回答一个问题：**代价够不够**

```
🔴 **若"撤退 = 免费跳过 + 只掉士气"** ⇒ 🔴 **那"硬打"就没意义了**（绕开更好）⚠️
   ⇒ 那正是 **红线 24（净代价必须 > 0）** 要防的 ✅
⇒ ✅ **裁定：撤退的实质代价 = 【没有胜利收益】**
   · ✅ **胜利才有**：胜场（`Wins`）· 掉落 · 传家宝 · 事件推进
   · ✅ **撤退没有**：**上面全部拿不到** ⇒ 📌 **那是【实质代价】** ✅
   · ✅ **另有**：**士气惩罚**（`retreat_success` / `retreat_success_with_death`，**后者更重**）
⇒ 📌 **净代价已 > 0** —— 因为**"跳过"换来的不是收益，而是【放弃了那格的收益】** ✅
```

🔴 **一处要澄清（关于 HP）**：
```
🔴 旧契约 `expedition.md:279` 写：撤退 ⇒ **HP 完全恢复** ⚠️
   ⇒ 🔴 **那【不是撤退的额外好处】** —— 那是 **"每场满血开局"的既有规则**（`#245`）
     ⇒ **打完没撤退、进入下一场，也是满血** ⇒ 所以"恢复"两条路一样 ✅

```

### 9.2 ✅ 新口径（**精确到列**）

### 9.3 🔴 并加一条**新读数**（因为"撤退"变场级后，需要一个新的量）

```
🆕 **「撤而不弃」的趟占比** = **本趟至少撤退 1 次、但最终【走完】的趟** 占比 ✅
   ⇒ 📌 **它回答一个新问题**：「**撤退能不能成为【有效策略】？**」
     · 若该值 **高** ⇒ ✅ **撤退是可用的战术**（退一场、继续走、最后走完）
