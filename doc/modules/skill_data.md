# 技能数据表（模块）

> 主文档：`GDD.md` §2.4 / `modules/skill.md`（模板定义）。
> **本文件是 `skill.md` 的 13 字段模板的「填实版」**——36 个我方技能 + 7 个敌方技能全部给出起手数值。
> 伤害用 `combat_math.md` §2 的公式算；所有数值为**起手值**，按 Monte Carlo 迭代。
>
> 决策：#153（本数据表）/#151（士气相关字段）。

---

## 0. 字段填写约定

| 字段 | 写法 |
|---|---|
| **站位** | 施法者必须站在这些位置才能用（我方 1~4 战斗位 / 5、6 支援位） |
| **倍率** | 乘在攻击力上。`0.55×2` = 两段各 0.55 |
| **命中 / 暴击** | 对基础值的**加减**（+5 = 命中率 +5 个百分点） |
| **附加** | 标注概率为**技能侧**，实际触发率 = 概率 × (1 − 目标对应抗性)，见 `combat_math.md` §4 |
| **位移** | 推/拉/自我移动 + 格数，需过目标位移抗性 |
| **限制** | 无 / CD N / 每场 1 次 |
| **士气** | 对士气的影响（本人 / 目标 / 全队） |
| **轴** | 距离轴 · 伤害轴 |

> 「全部」= 任意位置可用，是**换位不废人**的兜底技能（character.md §2）。

> - 降韧性的减益现在**同时削减伤（`韧性/250`）和美德率**（#158）——双威胁，符合设计意图。
> - 战术后果：**"优先切掉 4 号位施法者"** 仍是首要目标，但士气压力不再完全随他消失。
>
> - 位移技能的站位要求与 AI 优先级对齐（`enemy.md` §5.4）：小兵在 3/4 才突进，射手在 1/2 才后撤。
