## §1 🔴 这句话的三层含义（**先拆，再落**）

```
🔴 **① "战斗能跑了"** = **内核 + 战斗屏已可用** ✅
   （依据：557/557 · 六入口冒烟 0 错 · V3/V4 全绿 · 片 3.1 T1 达成）
🔴 **② "养成→再出发才是游戏本身"** = **循环的存在感 > 单场的深度** ⚠️
   ⇒ 📌 **即：玩家在 Hamlet 里【做的决定】必须【影响下一次远征】** ✅
🔴 **③ "把重心转过去"** = **接下来的里程碑以【闭环闭合】为准**，不以【战斗细节】为准 ✅
```

## §2 🔴 闭环的定义（**五环，缺一不算闭环**）

```
🔴 **【资源】远征带回东西**（传家宝 / 金币 / 名册经验）
   → **【花费】在 Hamlet 花掉**（升级建筑 / 治病 / 减压 / 招人 / 买补给）
   → **【变强】队伍实际变强**（等级 / 装备 / 技能 / 建筑等级）
   → **【再出发】下一次远征能感受到差异**
   → **【记录】玩家能看出"我上次的选择起了作用"**
⇒ 📌 **判据（一句话）**：**"同一张图，第二次去时队伍不一样，而玩家知道为什么"** ✅
```

🔴 **而"缺一不算闭环"的实例**：
```
❌ **带回东西但花不掉** ⇒ 资源无意义（**本会话已见过同类**：`#294` 的"补给过剩、花不出去"）⚠️
❌ **花掉了但不变强** ⇒ 花费无意义
❌ **变强了但感受不到** ⇒ 变强无意义（**下一趟的读数必须能证明差异**）⚠️
❌ **有差异但玩家不知道原因** ⇒ **选择无意义**（**红线 25：动作 ≠ 意义**）⚠️
```

### 7.2 🔴 裁定：「平台期」要处理 —— 但**先分清是哪一种**（不是先调数值）

```
🔴 **为什么它是【最关键的一个读数】**：
   **A4（感受到）要的正是"第二次去时队伍不一样"** —— 而**第 4 趟"十项全同" ⇒ A4 失效** ❌
⇒ 🔴 **所以要处理** —— 而**处置取决于原因是哪一种**：
   · **(a) 探针不真实**（口粮/柴火够用 ⇒ 不用花传家宝）⇒ ✅ **修探针**（**读数工具，不碰数值**）✅
   · **(b) 成长早期饱和**（升级成本跳档，一趟的传家宝不够再升）⇒ 🔴 **属数值 ⇒ 登记"解冻后校准"** ⚠️
```

### 7.3 🔴 判据（**可执行 —— 先加读数，不先改数值**）

```
🔴 **跑 N 趟（如 8~10）⇒ 看"起点变化"的【轨迹】**：
   · 若 **1~4 趟持续变化、5 趟起全同** ⇒ 倾向 **(b) 早期饱和** ⚠️
   · 若 **始终在变** ⇒ **(a) 不成立**（那就是探针侧的事）✅
⇒ 📌 **即：先加"多趟轨迹读数"，再谈处置** ——
   **因为"平台期"是【哪一段开始平】，而只看 4 趟【分不出"平了"还是"还没开始"】** ✅
   🎖️ **同族**：**"极端读数先怀疑口径"（红线 17 ⑧）** —— **"全同"是最极端的一类读数** ✅
```

### 7.4 🔴 而它带来一条**新的验收**

| # | 判据 |
|---|---|
| **A7** | 🔴 **起点变化【在 8~10 趟内不得【过早】归零】** —— **若第 5 趟起全同 ⇒ 必须能解释为什么** ✅ |
| **A8** | 🔴 **每趟至少【一项】可核对的变化**（**成长或损耗**）—— **"无变化"必须能归因**（如"刚好没花钱"）✅ |

```
📌 **而 A7/A8 的意义**：**它们把"养成有没有意义"从【一次性判断】变成【可追踪的曲线】** ✅
```

```
   ⇒ **而那等于【放弃可观测性】** ⇒ ✅ **所以它值得单列一条纪律** ✅
```
