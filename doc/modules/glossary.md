# 术语表与数据字典（模块）

> **用途**：统一文档与代码里的黑话。实现方在任何地方看到不认识的词，先查这里。
> **编号约定**：文中 `#N` 一律指 `state.md` 决策表的第 N 条决策，可回溯"为什么这么定"。
> **数值约定**：本表所有数值都是**起手值**，按 `verification.md` 的 Monte Carlo（≥300 场）迭代，不是最终值。
> **冲突约定**：`GDD.md` 与 `modules/` 冲突时，以 `modules/` 为准（模块是后写的、更细的一层）。

## 1. 位置与阵型

| 术语 | 定义 | 出处 |
|---|---|---|
| **战斗位** | 我方 1~4 号位。能用攻击类技能，是战斗的主体。 | GDD §1.1 |
| **支援位** | 我方 5、6 号位。**位置，不是职业**。支援位上**不能释放攻击类技能**，但可用增益 / 减益 / 治疗。 | #139 |
| **位置编号** | 由屏幕**中央向两侧递增**。我方 1 号位与敌方 1 号位隔着"空气"正面对峙。 | GDD §1.1 |
| **空气** | 敌我之间的间隔。只是视觉/镜头概念，**不占槽位、不参与位移**。 | GDD §1.1 |
| **槽位三态** | 每个槽位有且仅有三种状态：有角色 / 空 / 被障碍占据。 | GDD §1.1 |
| **障碍** | 「不会行动、只有血量的占位角色」。参与交换链、可被 AOE 打掉、**免疫所有 debuff**。不计入胜利条件。 | GDD §1.1 |
| **空** | 槽位三态之一（没人也没障碍）。**正常位移永远不会产生"空"**。 | formation.md |
| **空位** | 靠齐之后留在**队伍最后面**的连续空槽。只有死亡/离场才会产生。 | GDD §1.6 |
| **向中靠齐** | 角色死亡或离场时，后方角色**立即**向 1 号位方向补位，空位只留在最后。**虚弱者不参与前移**。 | GDD §1.6 |
| **逐级交换链** | 位移的实现方式：推 N 格 = 沿路依次交换 N 次（4→1 即 `4↔3`→`3↔2`→`2↔1`）。**位移永远不产生空位**。 | GDD §1.3 |
| **边界（硬墙）** | 最外侧单位被向外推时 → **位移失败，该单位不动**。 | GDD §1.7 |
| **位移抗性** | 抵抗被推/拉的概率属性。判定：`rand(0,100) >= 位移抗性` 即成功。**位移失败不影响伤害与其它效果**。 | combat_math §3 |
| **换人** | 支援位角色替换到战斗位（战斗位角色退到支援位）。是玩家主动操作，不是靠齐。 | #41b / GDD §1.4 |
| **换人保护** | 靠齐时虚弱者不参与前移——否则前面一死，虚弱者又被顶回战斗位挨打，保护失效。 | GDD §1.6 |

> ⚠️ **最常见的误读**：位移 ≠ 靠齐。位移走**交换链**（不产生空位），靠齐只在**死亡时**触发（产生空位）。
> 混淆这两条会让实现方在位移后错误地触发靠齐，阵型长度就不恒定了。

## 2. 技能

| 术语 | 定义 | 出处 |
|---|---|---|
| **站位要求** | 施法者**自己**必须站在哪些位置才能用。**位置 = 技能的使用门槛**。 | skill.md §2 字段2 |
| **目标位置** | 技能作用在哪些位置（我方/敌方 × 编号）。技能**不直接选目标，只选位置**。 | skill.md §2 字段3 |
| **技能灰显** | 站位不符 / 目标范围内全空 / CD 中 → 技能不可释放。**必须显示灰显原因**（UI 必显示项）。 | ui_spec.md |
| **部分非空** | 目标范围内部分位置有人 → **只对非空位置生效**，不浪费、不落空。 | GDD §4 |
| **距离轴** | 近战 / 远程。 | skill.md 字段12 |
| **伤害轴** | **物理 / 精神 / 无伤害**。⚠️ 这条轴现在决定三件事：走哪种减免、**掉不掉士气**、**护盾/护卫挡不挡**。 | #157 |
| **功能标签** | 输出 / 控制 / 位移 / 支援 / 治疗。 | skill.md 字段11 |
| **倍率** | 基于**攻击力**的乘数（伤害 = 攻击 × 倍率）。治疗**不吃倍率**，走固定值。 | combat_math §2 |
| **使用限制** | 无 / 冷却 N 回合 / **每场 N 次** / 每 N 回合一次。「每场 N 次」是用户额外要求的表达。 | skill.md 字段9 |

> ⚠️ **「无伤害」不等于「无效果」**：治疗、增益、纯位移技能的伤害轴填「无」，它们**不走减免、不触发死门、不掉士气**。

## 3. 战斗结算

| 术语 | 定义 / 公式 | 出处 |
|---|---|---|
| **命中** | `命中率 = 100 − 目标闪避 + 技能命中修正`，钳制 **[55, 100]** | combat_math §1 |
| **暴击** | 基础暴击率（角色属性），倍率 **1.5×** | combat_math §2 |
| **物理减免** | `物防 / (物防 + 30)`（递减公式，避免高防出现 0 伤害） | combat_math §2.1 |
| **精神减免** | `韧性 / 250`，**上限 40%**（#158 连续公式，推翻 #116 分档） | combat_math §2.2 |
| **伤害浮动** | 默认 **1.0（关闭）**。本作反老虎机立场的一部分。 | combat_math §2.1 |
| **伤害下限** | 任何来源的伤害**最低 1 点**（不出现 0 伤害的无效反馈） | combat_math §2.3 |
| **附加效果** | `实际概率 = 基础概率 × (1 − 对应抗性)`（**乘法不是减法**） | combat_math §4 |
| **护盾** | 按**次数**抵挡，不按点数。铁壁 = **2 次 / CD 4**。**只挡物理**，精神穿透。被抵挡的那次攻击**完全无效**（不扣 HP、不死门、不进虚弱）。 | #156 |
| **护卫** | 伤害**重定向**：保护者替被守护者挨这一下。每回合最多重定向 1 次，重定向后**再算一次保护者的防御**。 | #159 |
| **守护** | 坦克「盾墙」给友方上的 buff = **护卫（挡刀）+ 微量士气（+3）**。 | #136 |
| **治疗** | **固定值，不吃攻击力**（急救 12 / 群体绷带 5）。防止"堆攻击 = 堆治疗"。 | combat_math §8 |
| **自我伤害** | 固定值（殊死一搏 6 / 舍身 8）。可被护盾吸收，**可致死**（走死门）。 | combat_math §8 |
| **行动序列** | 按速度排序；**速度相同 → 位置靠前者先动**（编号小的先动） | GDD §2.5 |
| **减速** | 按**固定值**扣减（建议 −3 / 2 回合），不做百分比。 | GDD §2.5 |
| **眩晕** | **跳过本次行动**，随后状态结束（不是持续多回合的昏迷）。 | GDD §2.5 |

## 4. 士气系统

| 术语 | 定义 | 出处 |
|---|---|---|
| **士气** | 0~100，**起手 50**，钳制在 [0,100]。代表精神状态。 | morale.md §1 |
| **美德率** | `10% + 韧性 ÷ 2`（我方：35% / 37.5% / 40% / 42.5%） | #56 / #116 |
| **韧性** | **双职责属性**：① 精神伤害减免（韧性/250）② 美德率。**被降韧性 = 同时削减伤和美德率**。 | #158 |
| **满值美德** | 士气冲到 100 → 获得美德（持续**整场战斗**）+ 全队 **+10** 士气 → 自身士气**回到 50**。 | #155 |
| **崩溃判定** | 士气从 **>0 降到 0** 时触发：大概率折磨 / 小概率美德，然后**士气留在 0**。 | morale.md §4 |
| **折磨** | 负面状态。**概率触发型**（不是硬封禁）：自私→有概率拒绝治疗；恐惧→有概率拒绝释放；失控→有概率换目标。持续到**士气回 50**。 | morale.md §4.1 |
| **美德** | 正面 buff。持续到**战斗结束或士气再次归 0**。上限 **1 个**（不叠层）。 | #159 |
| **崩溃余烬** | 判定后士气停在 0 的状态。**余烬期间不再触发判定**（无论挨多少打）。折磨结束与恢复判定资格是**同一个点**（士气回 50）。 | morale.md §4.0 |
| **掉士气的唯一途径** | ⚠️ **只有精神类伤害掉士气**（−8，精神暴击 −12，AOE 精神 −5/目标）。**物理伤害不掉士气**。 | **#157** |
| **虚弱者挨打** | 额外 −5，**任意伤害类型**，每回合最多 1 次。（与 #157 有张力，保留现状，可推翻） | #157 |

> ⚠️ **#157 是本作最新的重大变更**：士气是精神状态，被刀砍不该动摇意志。
> 连带后果：① 干掉一层随机（10→9 层）② 嘲讽不再反噬坦克 ③ **施法者成为唯一的士气威胁源**，"切后排"的战术价值这才真正成立。

## 5. 生存链（本作最核心的一条链）

```
受伤 → HP 归零 →【不是死亡】→ 士气归 0 + 崩溃判定 → 进入【虚弱】
虚弱期间再次受伤 → 死门判定（按死门抗性）→ 失败 →【真正死亡】
```

| 术语 | 定义 | 出处 |
|---|---|---|
| **虚弱** | HP 归零后的状态：**伤害 −50% / 速度 −30% / HP 锁定 1**。士气归 0 并触发一次崩溃判定。 | GDD §3.3 |
| **死门** | **真正死亡的唯一途径**。虚弱状态下**再次受伤** → 按死门抗性判定存活。 | GDD §3.4 |
| **死门抗性** | 战士 70% / 坦克 75% / 军医 60% / 政委 60%。**折磨状态下 −10%**（#123）。 | #132 / #142 / #144 |
| **死亡** | 永久损失该角色。全队士气 −15。空出的位置触发**向中靠齐**。 | GDD §3.7 |
| **不判负** | 战斗位全是虚弱者**不判负**（#45）。防苟活靠§1.5.2 超时增援，不靠失败条件。 | GDD §3.5 |
| **撤退** | 主动撤离：**成功全队 −10 / 失败全队 −5**。 | #126 |

> ⚠️ **位移不产生伤害 → 不触发死门**（#117）。但**持续伤害（流血）会触发**。

## 6. 敌人与关卡

| 术语 | 定义 | 出处 |
|---|---|---|
| **敌方编队** | 只有 **4 个战斗位**，无支援位。**没有士气系统**。 | GDD §1.5 |
| **敌人 AI** | 固定优先级 + 小随机（**切片不做随机**，#112）。位置绑定技能 + 部分位移能力。 | enemy.md §5.4 |
| **超时增援** | 第 **6** 回合起仍未分胜负 → 增援。**有空位则填人，无空位则给在场敌人上增益**（不扩编）。 | GDD §1.5.2 |
| **死亡补位** | 敌人死亡后立刻填新单位。**切片不做**（与超时增援是两回事）。 | GDD §1.5.2 |
| **永久死亡** | 敌人死了就是死了，不复活。 | enemy.md |

## 8. 易混辨析（实现方最容易搞错的 9 对）

| # | A | B | 怎么分辨 |
|---|---|---|---|
| 1 | **位移** | **靠齐** | 位移走交换链、不产生空位；靠齐只在死亡时触发、产生空位 |
| 2 | **空** | **空位** | 「空」是三态之一，「空位」是靠齐后留在队尾的连续空槽 |
| 3 | **护盾** | **护卫** | 护盾 = 挡在自己身上（次数）；护卫 = 替别人挨（重定向） |
| 4 | **折磨** | **美德** | 都是崩溃判定的产物；折磨持续到回 50，美德持续到战斗结束 |
| 5 | **死门** | **死亡** | 死门是**判定**，死亡是**结果**。虚弱 + 受伤才走死门，HP 归零本身不死人 |
| 6 | **韧性** | ~~意志~~ | 「意志」是废弃旧名，现统一叫**韧性**（#56/#116） |
| 7 | **支援位** | ~~辅助（职业）~~ | 支援位是**位置**；「辅助/鼓舞者」作为**职业已被删除**（#139/#140） |
| 8 | **物理** | **精神** | 物理：走物防、不掉士气、**护盾/护卫可挡**；精神：走韧性、**掉士气**、护盾/护卫**挡不住** |
| 9 | **伤害轴「无」** | **无效果** | 「无」= 不走减免/死门/士气，但治疗、增益、位移照样生效 |
