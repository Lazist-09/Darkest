## 四、三处布局缺陷（全部先复现 · 再修）

### 4.1 整屏塌陷（`quest_select_skeleton.tscn`）

| 层 | 事实 |
|---|---|
| ① | 根节点 ＋ `QuestSelectCol` 缺 `size_flags_vertical = 3` ⇒ 变高容器高度塌到内容最小 |
| ② | `LayerTitle` 的 `parent` 指向错误节点 ⇒ 标题层挂错位置 |
| ③ | `QuestSelectCol.anchor_top` 缺省 ⇒ 与 DD 一手坐标（`name_pos y = 122 / 1080` ⇒ **0.1130**）不符 |

修法：补 `size_flags_vertical = 3` · `LayerTitle` parent 改 `.` · `anchor_top = 0.1130`；`QsWaveHighscoreTt` `anchor_top 0.7 → 0.6` ＋ `anchor_bottom 0.8481 → 0.7481`（**尺寸仍 DD 260×160，只挪位置**）。

### 4.2 弹窗行高恒 1px（`popup_line.tscn` · 模板级根因）

🔴 **引擎语义**：`Label` 的 `clip_text` ／ `text_overrun_behavior` 与 `autowrap_mode` **同开** ⇒ **最小高度恒 1px**。
修法：删 `clip_text = true` ＋ `text_overrun_behavior = 3`（**保留 `autowrap_mode = 2`**）。
**收益面 = 模板级**：所有使用 `popup_line` 的弹窗行同时受益（hamlet 冒烟无退化，见 §五）。

### 4.3 变高列表压占位（内建 `ScrollContainer` 定高 · 不挪 DD 坐标）

**复现**：m14g 5 条重叠原文（列表行 `@Label@14/16/17/18/19` ↔ 五个占位块的 `PurposeLabel`）：

| 列表行 | 被压占位 |
|---|---|
| `@Label@14` | `QsWaveHighscoreTt` |
| `@Label@16` | `QsDungeonXpBar` |
| `@Label@17` | `QsXpBarTtHotArea` |
| `@Label@18` | `QsTownEventIconTt` |
| `@Label@19` | `QsCampingTt` |

**修法（用户约束：能用引擎内建就不造轮子）**：新增**内建 `ScrollContainer` `QuestListScroll`**（parent = `QuestSelectCol/BodyRow`）包住原 `QuestList`：

````
custom_minimum_size = Vector2(220, 442)
size_flags_vertical = 0        # SHRINK_BEGIN
horizontal_scroll_mode = 0
vertical_scroll_mode = 1
````

**442 的推导（场景内已写明 = 读数常量 ＋ 过期护栏 = 重叠判据）**：

| 项 | 值 | 出处 |
|---|---|---|
| 占位盒顶（最小者） | **648** | `QsWaveHighscoreTt.anchor_top 0.6 × 1080`（其余 0.75/0.81/0.87/0.93 ⇒ 810/875/940/1004） |
| 列表顶 | **204** | 实测 `BodyRow` 顶 |
| 缝 | 2 | 预留 |
| ⇒ 定高 | **442** | 648 − 204 − 2 |

内容实测：行高 **49** · 间距 **6** · 15 行 ⇒ 内容高 ≈ **819** ⇒ 定高 442 后**可见 8 行 · 裁剪 7 行**（与冒烟「跳过裁剪外元素 7 个」**数上互证** ⇒ 反证行高非 1px 且裁剪生效）。

**判据行去重链**：`22`（m14a/m14b）⇒ `2`（m14c）⇒ `0`（m14d/m14f/m14f2/m14h）。
