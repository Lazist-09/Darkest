## 2. 🔴 缺口（按"挡不挡闭环"排序）
```
① 🔴🔴 **没有"再出发"的正反馈可见性**：现在回城能花钱、能升级，但**玩家看不到"这趟比上趟强在哪"**
   —— `RunProgress` 有 `RunsFinished` / `BattlesWon`，但**没有**"名册强度 / 传家宝存量 / 建筑等级"的**趋势读数**
   ⇒ 缺一条"**起点对比**"读数（第 1 趟 vs 第 N 趟：队伍平均 HP/士气/特质数、建筑等级、传家宝存量）⚠️
② 🔴 **招募是死内容**：初始名册 12/12 满员（上限 12）⇒ 玩家**永远不会**用到招募 ⚠️
   ⇒ 要么**初始不满员**（首趟即有减员/患病压力），要么**上限随建筑解锁提升**（`unlocks.json` 里已有 `roster_cap` 类？待核）
③ 🔴 **升级的"三选一"缺少张力**：4 种传家宝 → 3 栋建筑，实测"一趟（三场暗档）拿到的传家宝**不足以**一次升满三栋"
   （`HeirloomStockTests` 已锁这条）⇒ 有取舍 ✓ 但**缺"升级后明显变强"的关卡对照**（⇒ 同 ①）
④ ⚠️ **疾病/特质的"养成"只有惩罚面**：患病要花钱治、负面特质要花钱除 —— 但**正面成长**只有"锁正面特质"一条
   ⇒ 缺"**主动培养**"（练级/训练/装备）—— ⚠️ 是否要做由策划定（D D 里有营地技能/装备，我们装备面还没开）
⑤ ⚠️ **金钱的出口单一**：`economy.json` 里金钱用于减压/治病/升级；**没有"买装备/买补给"**（补给目前只在图里摸）
⑥ ✅ **合规项（发布前必核）**：`borrow/` **856 个文件**是借用美术（无授权）· `assets/heroes_placeholder` 是合规占位
   （`HeroAssets` 已落实"引用而非拷贝 / 缺槽点名 / 占位只从 `PlaceholderRoot` / 显式标注来源"✓）
   ⇒ 🔴 **发布前必须**：确认 `borrow/` 的授权，或**全部替换为原创/授权素材**（`assets_credits.md` A1 同族纪律）
```
