### ② `TuningConfig.Validate.ExpeditionSide.cs:65` —— 手写 target 取值

```csharp
// 改前：模式匹配里写死两个值，报错也写死两个值
if (tier.Target is not null && **tier.Target is not ("enemy_hp" or "enemy_resist")**)
    throw new InvalidDataException($"… target 只能是 **enemy_hp / enemy_resist**（或 null=待裁定）…");
// 改后：清单抽成局部常量，校验与文案都用它

```
⇒ 🎖️ **即：原来【校验】与【文案】各写一遍同一清单** ⇒ ⚠️ **两处都要改才同步** ✓
