## 2. 🔴🔴 三处不同（我方 vs 参考）

| 项 | **参考** | **我方** | 后果 |
|---|---|---|---|
| **第一道取整** | **`CeilToInt`**（向上） | **`Math.Round(AwayFromZero)`**（四舍五入） | 🔴 **对 `x=5.4`：参考 6 · 我方 5 ⇒ 差 1** |
| **第二道取整**（暴击） | `RoundToInt(damage × 1.5)` | 🔴 **没有这一步**（A3：`CritPct` 无消费点） | 🔴 **暴击未接线** |
| **伤害下限** | **`0`**（`if (damage < 0) damage = 0`） | 🔴 **`damageFloor` 默认 `1`** | 🔴 **见 §3 —— 会改变"能不能打死"** |
| 免伤 | `CanBeDamagedDirectly == false ⇒ 0` | 🔴 **未核** | 记**待核** |

### 🎖️ 我方原文（`BattleMath.cs:180-183`）

```csharp
public static int ApplyDamageRounding(double raw, int damageFloor = 1)
{
    int rounded = (int)System.Math.Round(raw, System.MidpointRounding.AwayFromZero);
    return System.Math.Max(damageFloor, rounded);
}
```
⇒ 🎖️ **即：我方用的是 `Round(AwayFromZero)` + 下限 1** ✓
   📌 **两者都与参考不同** ✓

## 3. 🔴 下限 `1` vs `0`：**这条会改变行为**（最值得报的一处）

```
🔴 **场景**：敌人剩 **1 HP**，且这一击被 `Prot` 吃光（`x` 算出来 < 1）：
   · **参考**：`ceil(x) = 1`（若 x>0）或 **0**（若 x ≤ 0 或免伤）⇒ **可能打 0** ⇒ **打不死** ✓
   · **我方**：`max(1, round(x))` ⇒ 🔴 **永远至少 1** ⇒ **一定能打死** ⚠️
⇒ 🔴 **即：我方"补刀"能力比参考强** ⚠️
   📌 **而这会穿透**：**死门判定**（HP 归零）· **击杀奖励** · **胜负判定** ✓
🎖️ **判据**：**"这个下限，是【防止 0 伤害】还是【保证至少 1 伤害】？"** ——
   **两者【不是一回事】**：
      · **防负数** ⇒ 下限 0（参考的做法）✓
      · **保证有伤害** ⇒ 下限 1（我方的做法）✓
   ⇒ ✅ **参考取的是第一种，我方取的是第二种** ⇒ 🔴 **是真差异，不是写法差异** ✓
```
