## 1. 我原定的三段判据，实测**只有第 ① 段能做**

```
原定：**① tag 命中 → ② `kind` 一致 → ③ 效果串逐项对上** ⇒ 才升"明确" ✓
🔴 **实测：只有 ① 能做，②③ 都缺前置** ⚠️
```

### ① tag 命中 —— ✅ **能做**（已完成）

| 我方 | `curio_type` | 参考候选数 | 我猜的那条在候选里 |
|---|---|---|---|
| `cur_altar` | `Worship` | 8 | ✅ `altar_of_light` |

⇒ 📊 **4/6 通过第 ① 段** ✓

### ② `kind` 一致 —— 🔴 **做不了：我方【没有 `kind` 字段】**

```
参考每条有 `kind`：**`Good` 23 · `Mixed` 31 · `Bad` 6** ✓
🔴 **我方 6 条【一条都没有这个字段】** ⚠️
⇒ 📌 **即："② 需要【先有字段才能比】"** ⇒ 这属于**「结构」不是「读数」** ✓
   ⇒ ⚠️ **不是"我读不出来"，是"字段不存在"**（两者必须分清 —— 纪律 BK）✓
```

### ③ 效果串逐项对上 —— 🔴 **做不了：两侧【没有公共词表】**

```
我方 `bare_hands[].kind` 全集（**11 个**）：
   `damage_buff` · `disease_one` · `firewood` · `food` · `gold` · `light` ·
   `morale_team` · `none` · `scout` · `support_pack` · `trait_positive` ✓
参考侧可用的"效果"表达（三段实测值）：
   `Loot` · `Quirk` · `Effect` · `Purge` · `No` · `Yes` · `Ruins` · `Warrens` · `1` · `3` · `4` ✓
🔴 **两侧词表交集 = 空** ⚠️
⇒ 📌 **要 ③ 就得先有一张【映射表】**（我方的 `food` ↔ 参考的哪个？）
   ⇒ ⚠️ **而那张表【没有人有】** —— 参考侧压根没有"食物"这个概念（它的 `Loot` 是"掉落表名"）✓
```

## 2. 🎖️ 但第 ① 段**已经足够做一件事**：**把 2 条降级**

```
✅ 通过 ① 的 4 条 ⇒ **保持"候选"**（不能升明确，因为 ②③ 缺前置）✓
🔴 未通过 ① 的 2 条 ⇒ **降级，且理由【可计算】**：
   ① `cur_sconce`（`Light`）⇒ **该 tag 不是参考标签**（0 候选）⇒ 🔴 **名字像而已** ✓
      补证：参考 `sconce` 的 `FULL CURIO?` = `[Effect, No, Purge]`（**No = 不做**）
         而我方 `cur_sconce` 是 `{chance:100, kind:"light", amount:30}`（**给光**）
         ⇒ **效果方向相反** ⚠️ ⇒ ✅ **降级依据充分** ✓
   ② `cur_supply_crate`（`Treasure`）⇒ 我猜的 `crate` **是 `Scrounging`** ⇒ ⚠️ **配错了** ✓
      而 `Treasure` 下有 **17 条候选** ⇒ 🔴 **究竟该配哪条，本件【判不了】** ✓
```

## 3. 🔴 而有一条**意外收获**：参考的**判定结构比我方细**

```
参考的一个奇物有**三段独立的结果**：
   `REGION FOUND` —— **在本区找到时**的结果（如 `[Loot, Ruins, Quirk]`）
   `ALL`          —— **通用**结果（如 `[Quirk, 4]`）
   `FULL CURIO?`  —— **拿齐整件**的结果（如 `[Effect, 1, Yes, Purge]`）
   ＋ 底部的 `results[]`（`result_type` = `Nothing`/…，带 `weight`/`chance`）
🔴 **而我方只有两个维度**：`bare_hands`（空手摸）· `item_results`（用物品交互）⚠️
⇒ 📌 **即：参考的"三段"与我方的"两维"【不是同一套切法】** ⚠️
   · 参考按**"你拿到了多少"**分（找到 / 通用 / 拿齐）
   · 我方按**"你用什么碰它"**分（空手 / 用物品）
   ⇒ 📌 **两者是【两个正交的维度】** ⇒ 🔴 **不能一一对应** ✓
   🎖️ **这解释了为什么 ③ 做不了**：**不只是词表不同，是【切分方式】都不同** ✓
```
