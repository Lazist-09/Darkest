## 1. 📊 扫 160 份编号报告里的数

```
📊 **共 135 个"**N 处/个/条/项/次**" 形式的数**：
   | 判据 | 处数 |

     很多数虽无"全仓"字样，**但给了具体文件 + 行号**
     （如「`abbey.building.json`（299 行）→ **10 处**：`19`、`28`、`36`…」）⇒
     ✅ **那比"全仓"更可复算**（能逐行核对）✓

## 4. 🎖️ 所以真正的结论是**「无法自动判定」**，不是「75 个都裸」

```
📊 **三个层次**：
   | 层 | 判法 | 结果 |
   |---|---|---|
   | **① 有范围标注** | 正则可判 | **13** ✓ |
   | **② 有文件/行号定位** | 正则可判 | **+47 ⇒ 60** ✓ |
   | **③ 点了 token/路径/字段** | 🔴 **正则判不了**（要人读）| **75 个里多数属此** ⇒ 人工抽验 |
⇒ 🎖️ **即：自动审计的边界在 ③** ⇒ ✅ **诚实结论：**
   **"13/135 显式声明全量 · 60/135 自动可定位 · 其余 75 需人读（抽验多数可复算）"** ✓
