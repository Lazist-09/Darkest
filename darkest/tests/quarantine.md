# 测试 quarantine 登记表（冻结读数）

**口径**：本表登记**因数值/平衡未校准而超线**的验收项。用例内**不放宽 band**，改为
「**实测 == 冻结值**」显式比对 —— 相等 ⇒ 打印 `WARN 待校准` 通过；**不等 ⇒ 红**。
这样 **band 与用例都留着**、读数不会静默漂移，且**读数一变就必须复裁**。
（依据：`报告` 判据 —— 「读数变了但没人知道 ⇒ 比没有读数更糟」。）
